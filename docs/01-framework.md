# 1단계 결과물: 통합 프레임워크

> `prompts/01-foundation.md`를 실행한 결과입니다. 2~5단계의 기준 문서이며, 5단계 점검에서 계속 고쳐 나갑니다.
> 이 도구는 전문 치료를 대체하지 않는 보조 도구입니다. 위기 시: 자살예방상담전화 **109** · 정신건강위기상담 **1577-0199** · 응급 **119**

## 0. 입력 정보와 가정

| 항목 | 내용 |
|---|---|
| 주로 겪는 어려움 | 불안·긴장 |
| 하루 가용 시간 | 10분 이하 |
| 상담·치료·약물 경험 | 없음 |
| 산출물 형태 | 웹앱(PWA) |

**이 정보에서 나온 설계 방향**
- **불안이 중심, 우울은 감시 대상.** 모듈과 라우팅은 불안 위주로 짜되, 불안이 오래가면 우울로 번지는 경우가 흔하므로 우울 신호(무기력, 흥미 저하)를 측정하고 대응 경로를 남겨 둡니다.
- **하루 10분 안에 끝나는 구조.** 모든 모듈에 1~3분짜리 최소 버전을 두고, 하루 총량은 기본 7~10분으로 잡습니다.
- **치료 경험이 없으므로 기법 설명을 쉽게, 그리고 전문가 연결을 더 적극적으로.** 시작 시점의 GAD-7 점수가 10점 이상이면 한 번은 전문가 평가를 받아 보도록 권합니다(6장).

**확인하지 못해 가정한 것** (5단계 첫 점검에서 확인)
- 불안의 유형은 특정하지 않았습니다. 일상적 걱정(범불안), 사회적 상황의 불안, 신체 증상이 강한 불안(공황)을 모두 다룰 수 있게 라우팅을 짰습니다. 공황 발작이 잦다면 호흡에 집중하는 모듈이 오히려 불안을 키울 수 있어 대체 경로를 두었습니다(2장, 6장).
- 명상 경험은 거의 없다고 가정하고 짧고 구체적인 지시문으로 시작합니다.

## 1. 통합 모델: 메커니즘 지도

### 1.1 핵심 아이디어: 불안을 "없애는" 것이 아니라 불안과의 관계를 바꾼다

불안 자체는 위협에 대비하는 정상적인 반응입니다. 문제가 되는 것은 불안을 **유지시키는 고리**입니다.

```
  위협 신호(상황·신체감각·생각)
          │
          ▼
  ① 과잉 경보 ── 편도체 등 위협 탐지 회로가 민감하게 반응, 몸이 긴장(심박·호흡·근육)
          │
          ▼
  ② 걱정·반추 ── "만약 ~하면?"을 반복하며 해결하려 함 (DMN·반복적 부정적 사고)
          │
          ▼
  ③ 회피·안전행동 ── 상황을 피하거나, 확인·안심 구하기로 당장 불안을 낮춤
          │
          ▼
  ④ 학습 실패 ── "피해서 괜찮았다"만 배우고 "견딜 수 있었다"는 배우지 못함
          │
          └──────► ①이 더 민감해짐 (고리 강화)
          
  + ⑤ 자기비판 ── "또 불안해하다니 한심하다" → 2차 불안, 고리에 연료 추가
```

이 도구의 모든 모듈은 이 고리의 어느 한 지점을 끊는 역할을 맡습니다.

**설계의 핵심 원칙: 진정 기법이 새로운 안전행동이 되지 않게 한다.**
호흡이나 그라운딩을 "불안을 당장 없애는 도구"로만 쓰면, "이걸 하지 않으면 큰일 난다"는 믿음이 생겨 회피의 한 형태가 될 수 있습니다(Salkovskis, 1991의 안전행동 개념; Craske et al., 2014의 억제 학습 모델). 그래서 이 도구는
- 진정 기법을 "불안을 없애는 것"이 아니라 **"생각할 수 있는 상태로 돌아오는 것"**으로 안내하고,
- 성과를 "불안이 몇 점 내려갔나"뿐 아니라 **"불안해도 하고 싶은 일에 다가갔나"**로도 측정합니다(5장).

### 1.2 메커니즘 지도

근거 수준: **강함**(여러 메타분석에서 일관됨) / **중간**(메타분석이 있으나 효과 크기가 작거나 이질적) / **예비**(소규모·초기 연구) / **가설**(이론적 추론 중심)

| # | 메커니즘 | 뇌과학적 설명 (정확한 버전) | 겨냥하는 기법 | 근거 수준 |
|---|---|---|---|---|
| ① | **과잉 경보·신체 긴장** | 불안장애에서 편도체·섬엽의 위협 반응이 높게 나타난다는 메타분석이 있습니다(Etkin & Wager, 2007). 자율신경계의 교감신경 활성(심박·호흡 증가)이 함께 나타납니다. 내쉬는 숨을 길게 하는 느린 호흡은 심박변이도를 높이고 각성을 낮추는 경향이 있습니다(Zaccaro et al., 2018 체계적 고찰). | 느린 호흡, 생리적 한숨(Balban et al., 2023), DBT TIPP, 그라운딩, 바디스캔 | 느린 호흡: 중간 / 생리적 한숨: 매일 연습 효과 예비~중간, 즉시 효과 예비 / 그라운딩: 예비(임상에서 널리 쓰이나 단독 검증 적음) / TIPP 구성요소 개별: 예비~중간 / TIPP 묶음 자체: 예비 |
| ② | **걱정·반추** | 자기 관련 생각과 마음 방황에 관여하는 DMN(Raichle et al., 2001)이 우울·불안에서 반추와 함께 과도하게 연결되어 있다는 연구가 있습니다(Hamilton et al., 2015). 숙련된 명상가에서 명상 중 DMN 활동이 낮았다는 연구가 있으나(Brewer et al., 2011), 소규모이고 인과 관계는 확립되지 않았습니다. | 마음챙김(생각 관찰), ACT 탈융합, 걱정 미루기(Borkovec et al., 1983), 감정 이름 붙이기 | 마음챙김의 불안 감소: 중간~강함(Hofmann et al., 2010; Hoge et al., 2023) / 걱정 미루기: 예비~중간 / DMN 기전 설명: 예비 |
| ③ | **회피·안전행동** | 공포는 지워지기보다 새로운 "안전 학습"이 기존 공포 기억을 억제하는 방식으로 줄어듭니다(억제 학습, Craske et al., 2014). 전전두엽(특히 복내측)이 편도체 반응 조절에 관여합니다. 피하면 이 새 학습이 일어나지 않습니다. | CBT 행동실험·점진적 노출, DBT 반대 행동, ACT 기꺼이 경험하기·전념 행동 | 노출 기반 CBT의 불안 효과: 강함(Hofmann & Smits, 2008; Carpenter et al., 2018) / ACT: 중간(A-Tjak et al., 2015) |
| ④ | **파국적 예측** | 불안할 때 위협의 확률과 심각성을 과대평가하고 대처 능력을 과소평가하는 경향(인지 편향). 불확실성을 견디기 어려워하는 성향이 걱정을 유지시킵니다(Dugas et al.의 불확실성 불내성 모델). | CBT 사고기록지(증거 검토), 행동실험(예측 검증), 불확실성 수용 연습 | CBT: 강함 |
| ⑤ | **자기비판·2차 불안** | 위협 체계가 외부뿐 아니라 자기 자신을 향할 때 지속적인 긴장이 생긴다는 이론(Gilbert의 자비중심치료 모델). 자기자비가 높을수록 불안·우울이 낮다는 메타분석(MacBeth & Gumley, 2012). | 자비명상, 자기자비형 확언, DBT 지혜로운 마음, ACT 관찰하는 자기 | 상관 연구: 중간 / 개입 효과: 예비~중간 / 뇌 기전: 가설 |
| ⑥ | **감정에 압도됨** | 감정에 말로 이름을 붙이면 편도체 반응이 줄고 우측 복외측 전전두엽 활동이 늘었다는 연구(Lieberman et al., 2007). 단, 실험실 연구이며 효과는 일시적입니다. | 감정 이름 붙이기, DBT STOP, 표현적 글쓰기(Pennebaker, 1997) | 이름 붙이기: 예비~중간(Lieberman et al., 2007; Kircanski et al., 2012) / STOP 단독: 예비 / 표현적 글쓰기: 중간(효과 작음, Frattaroli, 2006) |
| ⑦ | **활동 위축 → 우울 (감시)** | 불안으로 피하는 일이 늘면 보상 경험이 줄고 기분이 떨어지는 악순환. | 행동활성화(Ekers et al., 2014), 가치 명료화, 좋았던 일 기록 | 행동활성화의 우울 효과: 강함 / 감사 기록: 중간(효과 작음, Davis et al., 2016) |

### 1.4 세 치료법을 조화시키는 원칙

CBT는 "생각이 맞는지 따져보자", ACT는 "생각과 싸우지 말고 거리를 두자"라고 해서 충돌해 보입니다. 이 도구는 **각성 수준과 생각의 종류**에 따라 고릅니다.

```
                   지금 불안이 몇 점인가요? (0~10)
                               │
          ┌────────────────────┼─────────────────────┐
        7~10                 4~6                   0~3
   [몸 먼저: DBT/호흡]    [거리 두기: 마음챙김/ACT]   [따져보기·다가가기: CBT/ACT]
   생각을 다루기 전에      생각을 관찰하고 이름 붙임    예측을 검증하고, 가치 행동 계획
   각성부터 낮춘다                │
                                 ▼
                      그 생각은 어떤 종류인가요?
               ┌─────────────────┴─────────────────┐
       확인 가능한 구체적 예측                 답이 없는 반복적 "만약 ~하면?"
   ("발표 때 말을 더듬으면 다들 비웃을 거야")   ("혹시 나쁜 일이 생기면 어떡하지")
               │                                   │
         CBT: 증거 검토,                      ACT: 탈융합,
         행동실험으로 검증                     걱정 미루기, 불확실성 수용
```

**원칙 정리**
1. **몸 → 마음 → 행동 순서.** 각성이 높을 때(7점 이상) 긴 인지 작업은 효과가 떨어지므로 몸부터 진정시킵니다.
2. **생각의 내용과 씨름할지, 생각과의 관계를 바꿀지는 생각의 종류로 정한다.** 검증할 수 있으면 CBT, 답이 없는 반복이면 ACT.
3. **목표는 언제나 가치 있는 행동.** 진정, 재구성, 탈융합 모두 "하고 싶은 일로 돌아가기 위한 수단"입니다(ACT의 전념 행동과 CBT의 행동실험이 여기서 만납니다).
4. **변화와 수용은 함께 간다(DBT의 변증법).** "지금 불안한 나를 받아들이는 것"과 "불안을 줄이려 노력하는 것"은 모순이 아닙니다. 모든 안내 문구에 이 두 가지를 함께 담습니다.
5. **자기비판 금지 규칙.** 기법이 효과가 없어도 "내가 잘못했다"가 아니라 "이번엔 다른 걸 써보자"로 안내합니다.

## 2. 상태별 개입 라우팅

앱을 열면 **"지금 어떤가요?"** 화면에서 상태를 고르거나, 불안 점수로 자동 추천합니다.

### 판별 질문 (체크인)
1. 지금 불안·긴장은 몇 점인가요? (0~10)
2. 지금 가장 가까운 것은? (복수 선택 가능)
   - 몸이 떨리고 숨이 가쁘고 심장이 빨리 뛴다 → **A. 급성 불안**
   - 같은 걱정이 머릿속에서 계속 돈다 → **B. 걱정 루프**
   - 피하고 싶은 일이 있다 / 해야 할 일 앞에서 얼어붙었다 → **C. 회피 직전**
   - 감정이 너무 커서 무엇이든 해버릴 것 같다 → **D. 감정 폭주**
   - 기운이 없고 아무것도 하기 싫다 → **E. 무기력(우울 신호)**
   - 비교적 괜찮다 → **F. 안정**
3. 지금 쓸 수 있는 시간은? (1분 / 3분 / 5분 이상)
4. (B를 골랐다면) 이 걱정은 어떤 쪽인가요? 확인 가능한 예측 → CB02 / 답이 없는 "만약에" → AC01·CB03
5. (CB01 감정 이름 붙이기를 막 했다면 자동) 이 감정이 나에게 시키는 행동은? 피하기·숨기 → C 경로 / 계속 생각하기·확인하기 → B 경로 / 화내기 → D 경로의 STOP

### 상태별 경로

| 상태 | 첫 개입 (1~3분) | 이어지는 개입 (3~7분) | 하지 말아야 할 것 |
|---|---|---|---|
| **A. 급성 불안** (불안 7점 이상, 신체 증상) | 생리적 한숨 `BR01` 또는 그라운딩 `GR01` (개인 설정 "호흡보다 그라운딩 먼저"가 켜져 있으면 GR01) | 진정된 뒤: 감정 이름 붙이기 `CB01` → 지금 할 일 하나로 돌아가기 | 긴 사고기록, 원인 분석, 눈 감고 오래 몸 감각에 집중하기 |
| **B. 걱정 루프** (불안 4~6점) | STOP `DB02` → 감정 이름 붙이기 `CB01` | 생각의 종류 판별 → 구체적 예측이면 간이 사고기록지 `CB02`, 답 없는 반복이면 탈융합 `AC01` 또는 걱정 미루기 `CB03` | 걱정의 답을 찾을 때까지 계속 생각하기, 인터넷 검색·안심 구하기 반복 |
| **C. 회피 직전** | 느린 호흡 `BR02` (1분) | 기꺼이 경험하기 `AC03` → 반대 행동 `DB03`을 **하나의 "다가가기" 흐름**으로: "가장 작은 첫걸음" 하나 정하고 실행. DB03 사실 확인에서 불안이 사실에 맞으면(실제 위험) 반대 행동 대신 CB02의 대처 칸으로 (2차: 문제 해결 모듈) | 불안이 0이 될 때까지 기다렸다가 시작하기 |
| **D. 감정 폭주** | DBT TIPP `DB01` (찬물로 얼굴 적시기 또는 제자리 빠른 움직임 30초~1분) | STOP `DB02` → 지혜로운 마음 `DB05` 질문 하나 | 그 상태에서 중요한 결정·메시지 보내기 |
| **E. 무기력** (우울 신호) | 바디스캔 짧은 버전 `MD01` 또는 1분 몸 움직이기. **에너지 0~2점이면** MD01을 건너뛰고 CB05의 "아주 작은" 활동으로 바로 (바디스캔이 졸음으로 이어질 수 있음) | 행동활성화 `CB05`: 5분 안에 할 수 있는 작은 활동 하나 | "기분이 나아지면 하자"며 기다리기. **2주 이상 계속되면 6장 기준 확인** |
| **F. 안정** | 오늘의 루틴 모듈 | 생각 관찰 `MD02` (2차 이후: 자비명상 `MD03`, 주간이면 가치 나침반 `AC02`) | — (안정된 날이 연습하기 가장 좋은 날임을 안내) |

**모든 경로 공통 마무리**: 불안 점수 다시 기록 → "지금 하고 싶은 일, 해야 할 일로 돌아갈 준비가 됐나요?"

### 개인 설정이 바꾸는 경로
모듈을 쓰면서 생기는 개인 설정은 한곳에 모아 저장하고, 라우팅이 이를 따릅니다.

| 설정 | 정해지는 곳 | 라우팅에 미치는 영향 |
|---|---|---|
| 호흡보다 그라운딩 먼저 | BR01·BR02의 "숨에 집중하니 더 불안해요" 선택, 또는 설정 화면 | A 상태 첫 개입을 GR01로 / MD02 닻을 소리로 기본 설정 |
| TIPP 안전 확인 결과 | DB01 처음 사용 시 | 해당 항목이 있으면 DB01을 호흡·근육 이완만으로 안내 |
| 명상 닻(호흡/소리) | MD02 시작 화면 | MD02 안내 문구 |
| MD01 추천 끄기 | MD01의 "몸에 집중하니 불안해요" 선택 | E·F 상태와 루틴에서 MD01 대신 GR01·CB05 추천 |
| 걱정 시간 시각 | CB03 처음 사용 시 | 저녁 루틴에서 걱정 시간 → JR01 순서로 자동 연결 |
| 확언 끄기 | AF01 설정 | 아침 루틴과 모듈 마무리에서 확언 생략 |

## 3. 루틴 설계

하루 기본 총량 **7~10분**. 컨디션이 나쁜 날은 최소 버전만 해도 "오늘 했다"로 기록됩니다. **하루의 경계는 새벽 4시**입니다. 자정을 넘겨 쓴 저녁 기록은 전날 기록으로 보며, 6.2의 "3일 연속" 같은 판정도 같은 기준을 씁니다.

| 시간대 | 최소 (1분) | 기본 (3~5분) | 확장 (주말·여유 있는 날) |
|---|---|---|---|
| **아침** | 체크인(불안 점수) + 생리적 한숨 3회 | 체크인 + 느린 호흡 2분 + 오늘의 확언 1개 + "오늘 다가갈 작은 일 하나" 정하기 | 바디스캔 5분 또는 자비명상 5분 |
| **낮** (불안할 때) | STOP 또는 감정 이름 붙이기 | 상태별 라우팅(2장) 1회 | — |
| **저녁** | 오늘 불안 점수 + 한 줄 기록 | 저녁 3줄 기록 `JR01` (불안했던 순간 / 그때 한 것 / 다가간 일·좋았던 일) | 간이 사고기록지 또는 표현적 글쓰기(주 1회 이하) |
| **주간** (주말 10분) | 이번 주 점수 그래프 보기 | 주간 리뷰: 효과 있던 모듈, 다가간 일·피한 일 / 다음 주 작은 노출 목표 1개 | 가치 나침반 `AC02`, 행동실험 계획 `CB04` |

**걱정 시간**: 걱정 미루기 `CB03`를 쓰는 경우, 저녁 기록 직전 5분을 "걱정 시간"으로 둡니다. 잠자리 직전(최소 1시간 전 이후)은 피합니다. 알림이 없는 MVP에서는 저녁 기록을 열면 걱정 시간이 먼저 이어지는 방식으로 연결합니다. 걱정 메모는 걱정이 올 때 몇 초 안에 열려야 하므로 홈 화면에 고정 버튼으로 둡니다.

### 다시 시작하기 규칙
- 연속 기록(스트릭)을 보여주지 않습니다. 대신 **"이번 주 연습한 날 수"**를 보여줍니다. 끊김이 실패로 보이지 않게 하기 위해서입니다.
- 3일 이상 쉬었다가 돌아오면: "다시 와줘서 반가워요. 오늘은 1분만 해볼까요?"로 최소 버전만 제안합니다.
- 쉰 이유를 묻지 않습니다(자기비판을 부추길 수 있음). 5단계 점검에서 패턴으로만 봅니다.

| JR03 | 좋았던 일 세 가지 | 주의를 위협에서 균형으로 | ⑦ | 긍정심리 개입(Seligman), 감사 기록 | 1~2분 | 오늘 좋았던 일 세 가지와 그 일에서 내 역할 | 주간 평균 기분 | — (JR01 ③으로 대체) |

### 자기확언 `AF01`
자존감이 낮은 사람이 "나는 사랑받을 만하다" 같은 과장된 긍정 확언을 반복하면 오히려 기분이 나빠졌다는 연구가 있습니다(Wood, Perunovic & Lee, 2009). 반면 자신의 가치를 떠올리는 가치 확언은 위협 상황의 방어적 반응을 줄인다는 연구가 있습니다(Cohen & Sherman, 2014). 그래서 이 도구는 **믿을 수 있는 네 가지 형태**만 씁니다.

| 형태 | 원리 | 예문 | 와닿지 않을 때 더 약한 버전 |
|---|---|---|---|
| **수용형** | 지금 상태를 사실대로 인정 | "지금 불안한 건 내 몸이 나를 지키려고 하는 거다." | "지금 불안하다. 그게 지금의 사실이다." |
| **과정형** | 결과가 아닌 진행 중임을 강조 | "나는 불안과 함께 지내는 법을 배우는 중이다." | "오늘 1분 연습한 것도 배우는 과정이다." |
| **가치형** | 불안보다 중요한 것을 떠올림 | "불안해도, 나는 ___(가치)을 위해 이 일을 한다." | "이 일이 나에게 왜 중요한지 하나만 떠올려 본다." |
| **자기자비형** | 힘든 나에게 친구처럼 말함 | "힘든 순간이다. 누구에게나 이런 순간이 있다. 나에게 친절하자." | "지금 나를 비난하지 않는 것만으로도 충분하다." |

상태별로 맞는 형태: 급성 불안 → 수용형 / 회피 직전 → 가치형 / 자기비판 → 자기자비형 / 안정·아침 → 과정형·가치형. **MVP ✅**

## 5. 측정과 피드백 루프

### 0~10 점수 기준 (모든 점수에 공통)
| 점수 | 의미 |
|---|---|
| 0 | 전혀 없음 |
| 3 | 약간 있지만 하던 일을 할 수 있음 |
| 5 | 꽤 신경 쓰이고 집중이 어려움 |
| 7 | 강해서 다른 것을 하기 어려움 → 2장 라우팅에서 "몸 먼저" 기준 |
| 10 | 상상할 수 있는 가장 강한 정도 |

### 매일 (30초)
| 항목 | 방식 | 이유 |
|---|---|---|
| 불안·긴장 | 0~10 | 주 지표 |
| 기분 | 0~10 | 우울 신호 감시 |
| 에너지 | 0~10 | 무기력 감시 |
| 다가간 일 / 피한 일 | DB03 완료(첫걸음 "했어요"와 중간에 멈춘 시도 포함)는 **자동으로 "다가간 일"로 기록**, 저녁 3줄 기록에서는 확인·추가와 피한 일 체크만 | **회피가 줄고 다가감이 늘었는가**가 불안 점수보다 더 중요한 장기 지표 |
| 모듈 수행 | 자동 기록 (모듈 ID, 시작·종료, 전후 점수) | 모듈별 효과 분석 |
| 확언 믿는 정도 | AF01에서 자동 기록 (형태별 0~10) | 나에게 맞는 확언 형태 찾기. 자기자비형 믿는 정도의 변화는 메커니즘 ⑤(자기비판)의 간접 지표 |
| 하루 대표 기분 점수 | 저녁 기록 점수, 없으면 그날 체크인 중 가장 낮은 기분 점수 | 6.2 위기 기준("기분 2점 이하 3일 연속")과 주간 추이의 기준값 |

### 주기적 척도
| 척도 | 주기 | 해석 구간 (참고용, 진단 아님) |
|---|---|---|
| **GAD-7** (불안, Spitzer et al., 2006) | 시작 시 + 2주마다 | 0~4 최소 / 5~9 가벼움 / 10~14 중간 / 15~21 심함 |
| **PHQ-9** (우울, Kroenke et al., 2001) | 시작 시 + 2주마다 | 0~4 최소 / 5~9 가벼움 / 10~14 중간 / 15~19 중간~심함 / 20~27 심함 |

두 척도 모두 공개적으로 쓸 수 있고, 한국어판이 표준화되어 있습니다. 답하는 데 각각 1~2분이면 됩니다. **문항은 직접 번역하거나 다듬지 않고 공식 한국어판 문구를 그대로 쓰며, 앱에 출처를 표시합니다.**

### 조정 규칙
| 상황 | 조정 |
|---|---|
| 어떤 모듈을 5회 이상 썼는데 평균 전후 변화가 1점 미만 | 같은 상태의 다른 모듈을 추천 1순위로 올림. 단, 노출·행동 모듈은 즉각 변화가 작을 수 있으므로 이 규칙에서 제외하고 다가간 일 수로 판단 |
| 2주간 다가간 일이 0~1개 | 다음 주 노출 목표를 더 작게 나눔("가장 작은 첫걸음"을 반으로) |
| 비슷한 자동적 생각을 CB02로 3회 이상 기록 | 기록이 안심 구하기가 되고 있을 수 있으므로 CB02 대신 AC01 탈융합 또는 DB03 반대 행동(직접 확인) 추천. MVP에서는 "이전에 기록한 생각" 목록에서 같은 것을 고르는 방식으로 판별 |
| 진정 모듈(BR, GR, DB01)만 80% 이상 사용 | "진정 기법이 안전행동이 되고 있지 않은지" 안내하고, 기꺼이 경험하기·반대 행동을 함께 제안 |
| 2주간 GAD-7이 줄지 않음 | 5단계 점검에서 루틴 재설계. 4주간 변화 없으면 전문가 상담 권유 |
| 기분·에너지 점수가 2주 이상 4점 이하 | 무기력 경로(E)를 루틴에 추가하고, PHQ-9 즉시 실시 제안 |

## 6. 안전 장치

### 6.1 이 도구의 위치
- 앱 첫 실행과 "도움말"에: "이 앱은 불안을 다루는 기술을 연습하는 보조 도구이며, 진단이나 전문 치료를 대신하지 않습니다."
- **상담·치료 경험이 없으므로**, 시작 시 GAD-7 또는 PHQ-9가 10점 이상이면: "점수가 중간 이상이에요. 이 앱과 함께 전문가에게 한 번 평가를 받아 보면 도움이 될 수 있어요." 와 함께 정신건강복지센터(지역별 무료 상담)와 정신건강의학과 안내를 보여줍니다. 앱 사용을 막지는 않습니다.

### 6.2 위기 신호와 즉시 안내
| 신호 | 동작 |
|---|---|
| PHQ-9 9번 문항(죽음이나 자해에 대한 생각)에 1점 이상 | 결과 화면보다 먼저 위기 안내 화면 표시. "지금 안전한가요?" 질문 → 안전하지 않다면 109·119 바로 걸기 버튼 |
| 사용자가 직접 "위기" 버튼을 누름 (모든 화면에 상시 노출) | 위기 안내 화면 |
| 하루 대표 기분 점수(5장) 2점 이하가 3일 연속 | 부드러운 확인 메시지와 상담 연락처 안내 |
| 저녁 기록·CB05에서 기분 0~2점 입력 | 그 화면에서 "위기" 버튼을 강조 표시 |

**위기 안내 화면 내용** (네트워크 없이도 표시)
- 자살예방상담전화 **109** (24시간)
- 정신건강위기상담 **1577-0199** (24시간)
- 응급 상황 **119**
- 지금 바로 할 수 있는 것: 혼자 있지 않기, 믿을 수 있는 사람에게 연락하기, 위험한 물건에서 멀어지기
- 이 화면에서는 명상·저널링 기능을 권하지 않습니다.

**MVP에서 하지 않는 것**: 저널 글을 자동 분석해 위기를 판단하는 기능. 오탐(괜한 경고로 불신)과 미탐(놓쳤는데 안심) 위험이 크고, 글을 외부로 보내야 할 수 있어 개인정보 위험도 있습니다.

### 6.3 전문가 도움을 권하는 기준
- GAD-7 또는 PHQ-9가 15점 이상 → 적극 권유
- 10점 이상이 4주 이상 지속, 또는 2주 연속 악화
- 공황 발작이 주 1회 이상
- 불안 때문에 일·학업·관계에 뚜렷한 지장(출근·등교를 못 함 등)
- 술·약물로 불안을 다스리고 있음
- 잠을 거의 못 자는 날이 1주 이상 계속됨

### 6.4 기법이 오히려 해로울 수 있는 경우
| 상황 | 위험 | 대처 |
|---|---|---|
| 이완하려 하면 오히려 불안해짐 | **이완 유발 불안**이 일부 불안한 사람에게 나타남(Heide & Borkovec, 1983) | 눈 뜨고, 짧게(1분), 바깥 감각(소리·사물)에 집중하는 GR01을 대신 제안 |
| 공황 경향이 있어 호흡·심장 감각에 민감 | 몸 감각에 집중하면 공황이 촉발될 수 있음 | 호흡 모듈 첫 안내에 "불편하면 언제든 눈을 뜨고 그라운딩으로 바꾸세요" 표시, GR01을 기본 첫 개입으로 |
| 트라우마 경험 | 오래 내면에 집중하면 고통스러운 기억·해리가 생길 수 있음(Lindahl et al., 2017; Britton et al., 2021의 명상 부작용 연구) | 명상은 5분 이하, 눈 뜨고 가능, 언제든 멈출 수 있음을 안내. 표현적 글쓰기 중 압도되면 멈추고 GR01 |
| TIPP의 찬물·격한 운동 | 심장 질환, 저혈압, 섭식장애 등에서는 위험할 수 있음(DBT 매뉴얼의 주의사항) | 첫 사용 전 확인 질문. 해당하면 찬물·운동을 빼고 느린 호흡만 |
| 걱정·감정을 너무 자주 기록 | 자기 관찰이 증상에 대한 집착이 될 수 있음 | 체크인은 하루 최대 3회 권장, 5단계에서 부담 여부 점검 |

## 7. MVP 범위와 로드맵

### 7.1 산출물 형태: 웹앱(PWA)
선택하신 PWA는 이 프로젝트에 잘 맞습니다.
- **장점**: 한 번 만들면 휴대폰·PC 어디서나 실행. 홈 화면에 설치하면 앱처럼 열리고 오프라인에서도 작동. 앱스토어 심사가 없어 혼자 빠르게 고치고 배포 가능. 기록을 기기 안에만 저장하기 쉬워 개인정보에 유리.
- **한계와 대응**:
  - 아이폰 푸시 알림은 홈 화면에 설치해야 하고(iOS 16.4 이상) 동작이 불안정할 수 있음 → MVP는 알림 없이 시작
  - 브라우저 데이터를 지우면 기록이 사라질 수 있음 → 내보내기·가져오기 기능을 MVP에 포함
  - 화면이 꺼지면 타이머가 멈출 수 있음 → 모듈은 짧게, 종료 시각 기준으로 계산

### 7.2 MVP에 포함 (첫 버전)
1. **체크인**: 불안·기분·에너지 0~10, 상태 선택, 가용 시간
2. **상태별 추천**: 2장 라우팅 규칙대로 모듈 1개 + 대안 2개
3. **모듈 15개**: BR01, BR02, GR01, MD01, MD02, CB01, CB02, CB03, CB05, AC01, AC03, DB01, DB02, DB03, AF01 — 각각 최소 버전 + 기본 버전, 전후 점수 기록
4. **저녁 3줄 기록** `JR01`
5. **GAD-7·PHQ-9**: 시작 시 + 2주마다, 점수 구간 안내
6. **안전**: 상시 위기 버튼, PHQ-9 9번 연동, 오프라인 위기 안내, TIPP 주의 확인
7. **간단한 주간 화면**: 이번 주 연습한 날, 불안 평균 추이, 모듈별 평균 전후 변화, 다가간 일 수
8. **데이터**: 기기 안에만 저장, 내보내기(JSON/CSV)·가져오기·전체 삭제
9. **내 가치**: AF01 가치 확언 쓰기에서 저장하고 AC03·DB03·AF01 가치형에서 다시 씀 (2차 AC02 가치 나침반의 시작점)
10. **개인 설정**: 2장 "개인 설정이 바꾸는 경로"의 6개 항목
11. **빠른 진입**: 홈 화면에서 2번 탭 안에 최소 버전 모듈 시작, 걱정 메모 고정 버튼

### 7.3 나중에 (2차 이후)
- 모듈: MD03 자비명상, CB04 행동실험(DB03의 확장), AC02 가치 나침반, DB04 체인 분석, DB05 지혜로운 마음, JR02 표현적 글쓰기, **문제 해결**(불안이 사실에 맞을 때, DBT·CBT 문제 해결)
- 음성 가이드(녹음 또는 음성 합성)
- 루틴 리마인더 알림
- 개인화 추천(5장 조정 규칙의 자동화)
- 노출 사다리 저장·진행 추적 (사다리 만들기 자체는 MVP의 DB03 기본 버전에 포함)
- 앱 잠금 + 비밀번호 기반 암호화 (암호화 없는 잠금만으로는 실제 보호가 되지 않으므로 함께 구현)

### 7.4 다음 단계 프롬프트
1. **2단계** (`prompts/02-module-scripts.md`): MVP 모듈 15개를 3~5개씩 나눠 작성
   - 1회차: BR01, BR02, GR01, CB01, DB02 (급성 불안·걱정 루프의 첫 개입 — 가장 자주 쓰일 모듈)
   - 2회차: AC01, CB03, CB02, AC03, DB03 (걱정 루프·회피 직전 이어지는 개입)
   - 3회차: DB01, MD01, MD02, CB05, JR01, AF01 (나머지 + 저널링·확언)
2. **3단계** (`prompts/03-data-structure.md`): 구현 환경 = PWA, 나 혼자 사용, 기기 안에만 저장
3. **4단계** (`prompts/04-implementation.md`): 이 저장소에서 구현
4. **5단계** (`prompts/05-review-and-improve.md`): 2주 사용 후 첫 점검. 0장의 가정(불안 유형, 명상 경험) 확인. DB01의 강한 움직임(MVP는 1분)이 효과가 작다면 시간을 늘리는 것도 검토
