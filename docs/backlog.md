# 백로그 (MVP 범위 밖 아이디어)

4단계 구현 중 떠오른 아이디어를 적어 두는 곳입니다. MVP가 끝난 뒤 5단계 점검에서 우선순위를 정합니다.

- **도움말 시트 정리**: 모듈 진행 중 "힘들어요" 시트의 항목이 카드 안에 버튼이 들어간 모양이라 테두리가 겹쳐 보임. 디자인 정리 필요.
- **진행 중 세션 정리**: 앱을 닫아 `inProgress`로 남은 세션을 다음 실행 때 `abandoned`로 바꾸기 (설계 2.3의 status 정의).
- **DB02 "조금 기다렸다가 다시 생각" 시간 선택**: 2단계 문서의 10분 / 1시간 / 내일 선택과 홈 화면 카드. 지금은 계획을 글로만 적음.
- **세션 저장 실패 알림**: 저장소가 고장 났을 때 연습은 되지만 기록이 남지 않는다는 것을 모듈 시작 전에 알려 주기.
- **CB05 에너지 점수에 맞춘 활동 추천**: 2단계 문서대로 에너지 0~3이면 "아주 작은" 활동을 먼저. 지금은 전체 목록.
- **몸 그림 선택(bodyMap)**: 지금은 부위 이름 버튼. 그림으로 고르기.
- **다가가기 목록 화면**: 다가가고 싶은 일과 사다리, 지난 시도(예상 vs 실제)를 한눈에 보는 화면 (설계 7.1 `/approach`).
- **DB03 최소 버전 "지금은 못 하겠어요"**: 더 작은 첫걸음을 적은 뒤에도 마무리 문장이 "한 걸음 다가갔어요"로 나옴. 그 자리에서 해봤는지 한 번 더 묻기.
- **확언 믿는 정도 기록 위치**: 지금은 `sessions.answers.affirmation` 안에 묶여 있음. 5단계 점검에서 형태별 평균을 낼 때 꺼내기 쉽게 정리.
- **저녁 루틴의 마무리 문장 중복**: JR01 기본 버전의 마지막 문장("오늘 하루도 지나왔어요…")과 저녁 루틴 마무리 화면의 문장(날마다 바뀜)이 연달아 나올 수 있음. 루틴 안에서는 JR01 마지막 문장을 빼는 방법 검토.
- **오늘 다가갈 일 완료 표시**: 홈의 "다가갈 일"을 반대 행동으로 실제로 했을 때 ✓ 표시 (지금은 "다가간 일" 줄에 따로 나옴).
- **척도 문항 (작업 10 남은 일)**: GAD-7·PHQ-9 공식 한국어판 문구를 넣어야 검사가 열림. 이 세션의 네트워크 정책이 phqscreeners.com을 막고 있어 받지 못함. 방법은 `content/assessments/README.md`.
- **척도 안내 카드 미루기**: 설계 4.1의 "3일 동안 미루면 카드만 남기고 더 안내하지 않음". 지금은 실시할 때가 되면 계속 카드가 보임(문항이 들어오기 전에는 카드 자체가 안 뜸).
- **PHQ-9 제안 조건 확인**: "기분·에너지 4점 이하 14일"을 "기분 또는 에너지"로 구현함(제안이 늦는 것보다 이른 쪽이 안전하다고 판단). 5단계 점검에서 너무 자주 뜨는지 확인.
- **주간 화면 그래프 색 토큰**: 그래프 막대는 채도를 높인 `--chart`(밝은 #1f8a70 / 다크 #2fa585)를 씀. 주 색(`--accent`)은 회색으로 읽혀 dataviz 검사를 통과하지 못함. 디자인을 다듬을 때 함께 정리.
- **확언 형태별 믿는 정도 (1단계 5장)**: 주간 화면에 아직 없음. 5단계 점검 자료로 필요하면 추가.
- **온보딩 순서**: 설계 7.1은 척도를 3번째로 두었지만, 척도 화면을 다녀오는 흐름이 복잡해 마지막 화면의 "먼저 점검하기"로 옮김(문항이 준비된 경우에만 보임).
- **모두 지운 뒤 온보딩**: "모든 기록 지우기"는 온보딩 완료 표시도 지우므로 다음에 열면 처음 안내부터 다시 시작함(의도된 동작, 화면에 안내함).
