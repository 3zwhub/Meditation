# 2주 사용 점검표

MVP를 2주 동안 써 보면서 적는 표입니다. 2주가 지나면 이 표와 앱에서 내보낸 기록을 5단계 프롬프트(`prompts/05-review-and-improve.md`)에 넣어 점검합니다.

앱이 이미 자동으로 기록하는 것(점수, 연습, 다가간 일, 걱정 메모)은 다시 적지 않아도 됩니다. 여기에는 **앱이 알 수 없는 것**만 적습니다.

## 매일 (1분, 저녁 기록 뒤에)

| 날짜 | 추천이 맞았나 (예/아니요/잘 모름 + 한 줄) | 앱을 못 쓴 때와 이유 | 불편했던 화면이나 문장 | 도움이 됐던 순간 |
|---|---|---|---|---|
| | | | | |
| | | | | |

예시: `11/3 | 아니요 — 불안 8인데 STOP이 나와서 바꿈 | 점심 회의 직전에 열 틈이 없었음 | 사고기록지 질문이 너무 많음 | 지하철에서 그라운딩 1분`

## 주말 (5분, 주간 화면을 보면서)

- 이번 주 가장 자주 쓴 연습 3개와, 실제로 도움이 된 정도(체감)
- 주간 화면의 "연습별 변화"가 내 느낌과 맞았나
- 다가간 일: 예상했던 일이 실제로 일어났나. 다음 주에 해볼 작은 일
- 기록하는 것 자체가 부담이었나 (설계 5.4: 자기 관찰이 오히려 증상에 집착하게 만들지 않는지)
- 진정하는 연습만 하고 다가가기는 피하지 않았나

## 처음 2주 동안 확인할 가정 (1단계 0장)

1단계 설계는 아래를 모른 채로 가정했습니다. 써 보면서 맞는지 적어 주세요.

- [ ] 내 불안은 주로 어떤 쪽인가: 일상적 걱정 / 사회적 상황 / 갑자기 몸이 반응하는 공황
- [ ] 공황 발작이 있었다면 몇 번이었나 (주 1회 이상이면 전문가 상담 기준)
- [ ] 호흡에 집중하면 오히려 불안해지나 (그렇다면 설정의 "그라운딩 먼저")
- [ ] 명상 경험: 3분 기본 버전이 길게 느껴지나, 짧게 느껴지나
- [ ] 하루 10분이 실제로 가능했나

## 안전

- 위기 버튼을 누른 적이 있다면, 그때 화면이 도움이 됐는지 (내용은 적지 않아도 됩니다)
- 기분이 며칠 연속 많이 낮았거나, 자해·죽음에 대한 생각이 들었다면 이 점검보다 **전문가 상담이 먼저**입니다. 자살예방상담전화 109 · 정신건강위기상담 1577-0199 (24시간)

## 2주 뒤 5단계 점검에 가져갈 것

1. 설정 → **CSV 내보내기**(점수만 켜 둔 채로 충분) — 파일 5개
2. 이 점검표
3. 지난 2주 동안 있었던 특별한 일(시험, 이사, 아픔, 복약 변경, 상담 시작 등)
4. `docs/backlog.md`에서 우선순위를 정하고 싶은 항목
