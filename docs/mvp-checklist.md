# 첫 버전(MVP) 점검표

4단계 마지막 점검입니다. 1단계 7.2의 MVP 범위와 설계 8.2의 안전 시나리오를 하나씩, **무엇으로 확인했는지**와 함께 적었습니다.
테스트 수는 작성 시점 기준입니다(단위·컴포넌트 208개, 브라우저 e2e 77개).

표시: ✅ 완료 · ⚠️ 일부 · ❌ 안 됨

## 1. MVP 범위 (1단계 7.2)

| # | 항목 | 상태 | 확인한 방법 / 남은 것 |
|---|---|---|---|

| 2 | 상태별 추천: 1개 + 대안 2개 | ✅ | `src/domain/recommend.ts`. 상태 판별·7점 규칙·개인 설정·반복 방지·개인화·감정이 시키는 행동을 단위 테스트 24개로 확인 |
| 3 | 모듈 15개, 최소·기본 버전, 전후 점수 | ✅ | 16개 모듈(저녁 기록 포함)의 모든 버전 36가지를 e2e `modules.spec.ts`로 끝까지 진행. 안내 문장이 2단계 문서와 같은지 `tests/content/` |

MVP 밖에서 함께 만든 것: 아침·저녁 루틴(작업 9), 처음 실행 안내(작업 13), 조합 시퀀스 5개(작업 14), 다가가기 예정·결과 기록, 같은 생각 반복 감지.

## 4. 휴대폰에서 직접 확인할 것

배포한 뒤 휴대폰으로 한 번씩 확인해 주세요. 문제가 있으면 5단계 점검 때 함께 가져오면 됩니다.

- [ ] 주소를 열고 홈 화면에 추가(아이폰: Safari 공유 → 홈 화면에 추가 / 안드로이드: Chrome 메뉴 → 앱 설치)
- [ ] 홈 화면 아이콘으로 열었을 때 주소창 없이 앱처럼 열림
- [ ] 비행기 모드에서 열기 → "위기" 버튼 → 연락처가 보임
- [ ] 위기 화면의 109 버튼을 누르면 전화 앱에 번호가 뜸(실제로 걸지 않아도 됨)
- [ ] 느린 호흡 기본 버전 중 화면이 꺼지지 않음(지원하는 기기에서), 꺼졌다 켜도 시간이 맞음
- [ ] 글자 크기 130%·160%에서 버튼과 글자가 잘리지 않음
- [ ] 설정 → 백업 내보내기로 파일이 저장됨
