# MD01 짧은 바디스캔

## A. 메타 정보

| 항목 | 내용 |
|---|---|
| 모듈 ID | MD01 |
| 이름 | 짧은 바디스캔 |
| 출처 기법 | 마음챙김 기반 스트레스 감소(MBSR, Kabat-Zinn)의 바디스캔, 짧게 줄인 버전 |
| 겨냥 메커니즘 | ① 신체 긴장 알아차림, ⑦ 활동 위축(몸 감각으로 다시 연결) |
| 적합한 상태 | F. 안정(연습하기 좋은 때), 아침·저녁 확장 루틴, DB03 실행 후 남은 긴장 정리, 잠들기 전 |
| 피해야 할 상태 | 불안 7점 이상(→ BR01·GR01), 몸 감각에 집중하면 더 불안해지는 경우(이완 유발 불안), 트라우마 기억이 몸 감각과 연결된 경우 → 눈 뜨고 짧게, 또는 GR01 |
| 소요 시간 | 최소 1분 / 기본 3분 / 확장 5분 |

**근거에 대한 메모**: 바디스캔은 MBSR·MBCT의 핵심 연습이며, 이 프로그램들은 불안과 우울을 줄이는 근거가 있습니다(Hofmann et al., 2010; Hoge et al., 2023). 바디스캔만 따로 짧게 한 효과는 덜 연구되었습니다. (근거 수준: 프로그램 전체 중간~강함 / 짧은 바디스캔 단독 예비)

**설계 의도**: 목표는 **이완이 아니라 알아차림**입니다. "편안해지세요"라고 하면 편안해지지 않을 때 실패감이 생기고, 일부 불안한 사람은 이완하려 할 때 오히려 불안해집니다(Heide & Borkovec, 1983). 그래서 "느껴지는 것을 그대로 알아차리기"로 안내하고, 눈은 뜨고 해도 된다고 처음부터 말합니다.

## B. 시작 전 안내

> 불안할 때 우리는 머릿속에서만 살게 돼요. 이 연습은 잠깐 몸으로 내려와 보는 거예요.
> 몸을 편안하게 만들려고 애쓸 필요는 없어요. 지금 느껴지는 것을 그냥 알아차리기만 하면 돼요. 눈은 감아도, 떠도 괜찮아요.

[화면] 자세 선택: 앉아서 / 누워서 (누워서 선택 시 "잠들어도 괜찮아요, 낮이라면 앉아서 해보세요" 안내)

## C. 본 스크립트

### 최소 버전 (1분, 세 곳)

> 지금 앉아 있거나 누워 있는 그대로 있어 보세요. (쉼 3초)
> 
> **발**. 발바닥이 바닥이나 신발에 닿아 있는 느낌을 알아차려 보세요. 따뜻한지, 차가운지, 아무 느낌이 없는지. (쉼 10초)
> 
> **배와 가슴**. 숨을 쉴 때 배나 가슴이 움직이는 걸 느껴 보세요. 숨을 바꾸지 않아도 돼요. (쉼 12초)
> 
> **손과 얼굴**. 손이 어디에 닿아 있는지, 얼굴에 힘이 들어가 있는지 살펴보세요. 힘이 들어가 있다면, 그걸 알아차린 것만으로 충분해요. (쉼 12초)
> 
> 이제 몸 전체를 한 번 느껴 보고, 천천히 주변으로 돌아오세요.

### 기본 버전 (3분)

> 편한 자세로 있어 보세요. 눈을 감는 게 편하면 감고, 아니라면 앞쪽 바닥을 부드럽게 바라보세요. (쉼 3초)
> 숨을 한 번 천천히 내쉬어 보세요. (쉼 5초)
> 
> 지금부터 발에서 머리까지, 몸의 여러 곳에 차례로 주의를 옮겨 볼 거예요. 각 부분에서 느껴지는 것을 알아차리기만 하면 돼요. 아무 느낌이 없어도, 그것도 하나의 알아차림이에요. (쉼 3초)
> 
> **발**. 발가락, 발바닥, 발뒤꿈치. 바닥에 닿는 느낌, 양말의 감촉, 온도. (쉼 15초)
> 
> **다리**. 종아리와 무릎, 허벅지. 의자나 바닥에 닿아 있는 부분과 닿지 않은 부분. 무게가 느껴지나요? (쉼 15초)
> 
> **배와 허리**. 숨을 쉴 때 배가 부풀고 꺼지는 움직임. 허리가 의자에 기대어 있는 느낌. (쉼 15초)
> 
> **가슴과 등**. 숨이 들어오고 나가는 가슴. 심장이 뛰는 느낌이 느껴질 수도 있어요. 느껴지면 느껴지는 대로, 바꾸려 하지 않고요. (쉼 15초)
> 
> **손과 팔**. 손끝, 손바닥, 손목, 팔. 손이 무엇에 닿아 있는지. 따끔거림, 따뜻함, 무거움. (쉼 15초)
> 
> **어깨와 목**. 많은 사람이 긴장을 이곳에 쌓아 둬요. 어깨가 올라가 있는지, 목이 굳어 있는지 살펴보세요. 내려놓고 싶다면 내쉬는 숨에 살짝 내려놓아도 좋아요. (쉼 15초)
> 
> **얼굴과 머리**. 턱, 입 주변, 눈 주위, 이마. 이를 꽉 물고 있지는 않은지. 머리 꼭대기까지. (쉼 15초)
> 
> 이제 몸 전체를 한꺼번에 느껴 보세요. 발끝부터 머리까지, 숨 쉬고 있는 하나의 몸. (쉼 10초)
> 
> 생각이 몇 번이나 다른 곳으로 갔다면, 그건 아주 자연스러운 일이에요. 알아차리고 돌아온 횟수만큼 연습한 거예요. (쉼 3초)
> 손가락과 발가락을 조금 움직이고, 준비되면 눈을 떠 주세요.

### 확장 버전 (5분)
각 부위의 쉼을 25~30초로 늘리고, "가장 긴장이 느껴지는 곳"에서 한 번 더 머무는 단계(30초)를 추가합니다. "그곳으로 숨이 흘러간다고 상상하며, 긴장이 있을 자리를 내준다"(AC03의 숨으로 감싸기와 같은 원리).

**성찰 질문 1개**: "긴장이 가장 많이 느껴진 곳은 어디였나요?" (몸 그림에서 선택) — 쌓이면 주간 화면에 "자주 긴장하는 곳" 표시, 다음 최소 버전에서 그 부위를 포함

**다음 연결**

- 무기력 상태(E)에서 했다면 → CB05 작은 행동 하나
- 잠들기 전 → 그대로 마무리

## E. 문제가 생길 때

| 어려움 | 대처 |
|---|---|
| 몸에 집중하니 오히려 불안해져요 | 일부 사람에게 흔한 반응이에요. 눈을 뜨고, 최소 버전(세 곳)만 하세요. 계속 불편하면 GR01처럼 바깥 감각을 쓰는 연습이 더 맞을 수 있어요(설정에서 MD01 추천 끄기 가능). |
| 심장 뛰는 게 느껴져서 무서워요 | 가슴 부위는 건너뛰어도 괜찮아요. 화면의 "이 부위 건너뛰기" 버튼을 누르세요. |
| 아무 느낌이 없어요 | 그것도 알아차림이에요. "지금 발에서는 특별한 느낌이 없구나"로 충분해요. 연습할수록 미세한 감각이 느껴지기도 해요. |
| 잠이 와요 | 밤이라면 괜찮아요. 낮이라면 앉아서, 눈을 뜨고 해보세요. |
| 생각이 계속 끼어들어요 | 아주 자연스러운 일이에요. "생각"이라고 마음속으로 이름 붙이고, 지금 차례인 몸 부위로 돌아오세요. |

**즉시 멈춰야 하는 신호**: 고통스러운 기억이 떠오르거나, 몸이 내 것이 아닌 것처럼 느껴지는 현실감 상실 → 눈을 뜨고 멈춘 뒤 GR01. 이런 일이 반복되면 전문가와 상의하는 것을 권합니다.

**위기 신호**: 자해나 죽음에 대한 생각이 든다면 연습을 멈추고 위기 안내 화면(109 · 1577-0199 · 119)으로 이동합니다.
