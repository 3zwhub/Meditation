# BR01 생리적 한숨

## A. 메타 정보

| 항목 | 내용 |
|---|---|
| 모듈 ID | BR01 |
| 이름 | 생리적 한숨 (두 번 들이쉬고 길게 내쉬기) |
| 출처 기법 | 호흡 조절 연구의 "주기적 한숨(cyclic sighing)" (Balban et al., 2023) |
| 겨냥 메커니즘 | ① 과잉 경보·신체 긴장 |
| 적합한 상태 | A. 급성 불안, C. 회피 직전, D. 감정 폭주(TIPP 다음), 아침 루틴 |
| 피해야 할 상태 | 호흡에 집중하면 더 불안해지는 경우, 숨이 막히는 느낌이 이미 강한 경우 → GR01로 대체 |
| 소요 시간 | 최소 30초~1분(3회) / 기본 3분 / 확장 5분 |

**근거에 대한 메모**: Balban et al.(2023)은 건강한 성인이 하루 5분씩 한 달간 연습했을 때 기분이 좋아지고 호흡수가 낮아졌다고 보고했습니다. 한두 번의 한숨으로 즉시 진정된다는 효과는 이 연구에서 직접 검증한 것이 아니므로, 앱에서는 "빠르게 진정될 수 있다"가 아니라 "몸에 긴장을 낮추는 신호를 보내는 연습"으로 안내합니다. (근거 수준: 예비~중간)

## B. 시작 전 안내

> 사람은 긴장이 쌓이면 저절로 한숨을 쉬어요. 이 연습은 그 한숨을 일부러, 천천히 해보는 거예요.
> 숨을 짧게 두 번 들이쉬고 길게 내쉬면, 내쉬는 숨이 몸에 '이제 조금 느슨해져도 된다'는 신호를 보내는 데 도움이 될 수 있어요.

## C. 본 스크립트

### 최소 버전 (30초~1분, 3회)

[화면] 원 애니메이션: 들이쉼 1(크게 커짐) → 들이쉼 2(조금 더 커짐) → 내쉼(천천히 작아짐, 들이쉼보다 두 배 길게)

> 편한 자세로 있어도 괜찮아요. 눈은 떠도, 감아도 돼요.
> 코로 숨을 들이쉬세요. (쉼 2초)
> 끝에서 한 번 더, 짧게 들이쉬세요. (쉼 1초)
> 이제 입으로 천천히, 길게 내쉬세요. (쉼 5초)
> 
> 다시 한 번. 코로 들이쉬고 (쉼 2초) 한 번 더 짧게 (쉼 1초)
> 입으로 길게 내쉬세요. (쉼 5초)
> 
> 마지막으로 한 번 더. 들이쉬고 (쉼 2초) 한 번 더 (쉼 1초)
> 길게 내쉬세요. (쉼 6초)
> 
> 잘하셨어요. 이제 평소처럼 숨 쉬세요.

### 기본 버전 (3분)

> 편한 자세로 앉거나 서 보세요. 어깨에 힘이 들어가 있다면 살짝 내려놓아도 좋아요. (쉼 3초)
> 
> 지금부터 3분 동안, 두 번 들이쉬고 길게 내쉬는 숨을 천천히 반복할 거예요.
> 숨을 크게 들이쉬려고 애쓰지 않아도 돼요. 평소보다 조금만 더, 편안한 만큼만이에요. (쉼 2초)
> 
> 코로 들이쉬세요. (쉼 2초)
> 끝에서 짧게 한 번 더. (쉼 1초)
> 입으로, 풍선에서 바람이 빠지듯 천천히 내쉬세요. (쉼 5초)
>
> [화면] 이 주기를 원 애니메이션과 함께 반복(약 1회당 8~10초). 30초마다 아래 문장 중 하나를 순서대로 넣음
>
> - "내쉴 때 어깨와 턱이 조금씩 풀리는 걸 느껴 보세요." (쉼 3초)
> - "생각이 떠올라도 괜찮아요. 그냥 다시 내쉬는 숨으로 돌아오세요." (쉼 3초)
> - "숨이 조금 어지럽게 느껴지면 속도를 늦추거나 평소 숨으로 쉬어도 돼요." (쉼 3초)
> - "내쉬는 숨이 들이쉬는 숨보다 길면 충분해요. 숫자를 정확히 맞출 필요는 없어요." (쉼 3초)
>
> (2분 50초 지점)
> 이제 마지막 숨이에요. 들이쉬고 (쉼 2초) 한 번 더 (쉼 1초) 길게 내쉬세요. (쉼 6초)
> 
> 이제 평소처럼 숨 쉬면서, 지금 몸이 어떤지 잠깐 살펴보세요. (쉼 5초)

### 확장 버전 (5분)
기본 버전과 같은 주기를 5분 동안 반복합니다(Balban et al., 2023에서 사용한 시간). 30초 안내 문장을 처음 한 바퀴만 넣고 이후에는 소리 없이 원 애니메이션만 보여줍니다.

## D. 마무리

[화면] 지금 불안·긴장은 몇 점인가요? 0~10 (시작 점수 {before} 함께 표시)

> 점수가 그대로여도 괜찮아요. 이 연습은 불안을 없애는 게 아니라, 다음 걸음을 뗄 수 있을 만큼 몸을 정돈하는 거예요.

**성찰 질문 1개**: "숨을 내쉴 때 몸의 어느 부분이 가장 먼저 느슨해졌나요?" (선택: 어깨 / 턱 / 가슴 / 배 / 잘 모르겠음)

**다음 연결**
- 아직 7점 이상 → GR01 그라운딩 1분
- 4~6점, 머릿속이 시끄러움 → CB01 감정 이름 붙이기 → 상태별 경로(B. 걱정 루프)
- 피하려던 일이 있었음 → AC03 기꺼이 경험하기 → DB03 반대 행동
- 3점 이하 → "하던 일로 돌아가 볼까요?"

## E. 문제가 생길 때

| 어려움 | 대처 |
|---|---|
| 어지럽거나 손끝이 저려요 | 숨을 너무 많이, 빨리 쉬고 있을 수 있어요. 들이쉬는 양을 줄이고 평소 숨으로 몇 번 쉬세요. 계속되면 멈추고 GR01로 바꾸세요. |
| 두 번째 들이쉼이 잘 안 돼요 | 첫 숨을 조금 덜 들이쉬면 두 번째 숨이 들어갈 자리가 생겨요. 안 되면 한 번 들이쉬고 길게 내쉬기만 해도 괜찮아요. |
| 숨에 집중하니까 오히려 더 불안해져요 | 몸 안의 감각에 주의를 두면 더 불안해지는 사람도 있어요. 바로 눈을 뜨고 GR01(바깥 감각에 집중)로 바꾸세요. 앞으로는 GR01을 먼저 추천하도록 설정할 수 있어요. |
| 효과가 없는 것 같아요 | 한두 번 만에 달라지지 않는 게 보통이에요. 이 모듈의 변화는 기록이 쌓이면 주간 화면에서 볼 수 있어요. |

**즉시 멈춰야 하는 신호**: 가슴 통증, 심한 어지러움, 숨이 막혀 공황이 커지는 느낌 → 멈추고 평소 숨으로 돌아온 뒤, 주변에 보이는 사물 5개의 이름을 소리 내어 말하기(GR01 최소 버전). 가슴 통증이 계속되면 의료적 도움을 받으세요(응급 119).
