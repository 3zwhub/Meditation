# CB01 감정 이름 붙이기

## A. 메타 정보

| 항목 | 내용 |
|---|---|
| 모듈 ID | CB01 |
| 이름 | 감정 이름 붙이기 |
| 출처 기법 | 정서 명명(affect labeling) 연구(Lieberman et al., 2007), CBT의 감정 확인 단계, DBT 정서 조절의 "감정 관찰하고 이름 붙이기" |
| 겨냥 메커니즘 | ⑥ 감정에 압도됨, ② 걱정·반추(다음 개입으로 가는 관문) |
| 적합한 상태 | B. 걱정 루프 첫 개입, A. 급성 불안이 조금 가라앉은 뒤, 감정이 뒤섞여 무엇인지 모를 때 |
| 피해야 할 상태 | 불안 8점 이상이면 먼저 BR01·GR01·DB01로 각성을 낮춘 뒤 |
| 소요 시간 | 최소 30초~1분 / 기본 2~3분 |

**근거에 대한 메모**: 감정을 말로 표현하면 편도체 반응이 줄었다는 fMRI 연구(Lieberman et al., 2007), 거미 공포 노출 중 감정을 말로 표현한 집단의 생리적 반응이 더 줄었다는 연구(Kircanski, Lieberman & Craske, 2012)가 있습니다. 실험실 연구이며 효과가 일시적이므로 "다음 기법으로 가는 출발점"으로 씁니다. (근거 수준: 예비~중간. 앱 인용 전 원문 확인)

## B. 시작 전 안내

> 감정이 커지면 머릿속이 하나의 큰 덩어리처럼 느껴져요. 그 덩어리에 이름을 붙여 보면, 감정과 나 사이에 아주 작은 틈이 생길 수 있어요.
> '나는 불안하다'가 아니라 '나는 지금 불안을 느끼고 있다'로요.

[화면] 지금 감정의 강도는 몇 점인가요? 0~10

## C. 본 스크립트

### 최소 버전 (30초~1분)

[화면] 감정 단어 버튼 8개(가장 자주 쓰는 것): 불안 · 걱정 · 긴장 · 두려움 · 초조 · 막막함 · 짜증 · 슬픔 / "다른 감정" 버튼

> 숨을 한 번 내쉬어 보세요. (쉼 3초)
> 지금 느끼는 감정에 가장 가까운 단어 하나를 골라 보세요. 정확하지 않아도 괜찮아요.

[화면] 선택 후:

> 이렇게 말해 보세요. 소리 내도, 마음속으로 해도 돼요.
> **"나는 지금 {감정}을 느끼고 있다."** (쉼 5초)
> 
> 감정을 바꾸려 하지 않아도 돼요. 그냥 '이게 지금 여기 있구나' 하고 알아차리는 것만으로 충분해요.

### 기본 버전 (2~3분)

**1. 감정 고르기** (최대 2개)

[화면] 감정 단어 목록(묶음별, 펼치기 가능)

| 묶음 | 단어 |
|---|---|
| 불안 계열 | 불안, 걱정, 긴장, 초조, 조마조마함, 두려움, 겁남, 막막함, 당황, 압도됨 |
| 슬픔 계열 | 슬픔, 서운함, 외로움, 허전함, 무기력, 실망 |
| 화 계열 | 짜증, 답답함, 억울함, 화, 분함 |
| 자기 관련 | 부끄러움, 창피함, 죄책감, 자책, 초라함 |
| 몸 상태 | 피곤함, 지침, 예민함 |

> 지금 느끼는 감정을 하나, 또는 두 개까지 골라 보세요.
> 여러 감정이 섞여 있는 건 자연스러운 일이에요.

*작성 예시*: 불안(7), 부끄러움(4)

**2. 강도 표시**

> 각 감정은 몇 점쯤인가요? (0~10)

**3. 몸 어디에서 느껴지나요?**

[화면] 몸 그림에서 부위 누르기: 머리 · 얼굴/턱 · 목/어깨 · 가슴 · 배 · 손 · 다리 · 잘 모르겠음

> 감정은 몸 어딘가에서 느껴지는 경우가 많아요. 가장 강하게 느껴지는 곳을 눌러 보세요.

*작성 예시*: 가슴(조이는 느낌), 배(울렁거림)

**4. 무엇이 이 감정을 불러왔나요?** (한 줄, 건너뛰기 가능)

> 감정이 시작된 순간을 떠올려 보세요. 무슨 일이 있었나요? 어떤 생각이 들었나요?

*작성 예시*: "내일 팀 회의에서 발표하라는 메시지를 받았다. '망치면 어떡하지'라는 생각이 들었다."

**5. 이 감정이 나에게 시키는 행동은?**

[화면] 선택: 피하고 싶다 · 확인하고 싶다(검색, 다시 보기, 물어보기) · 계속 생각하고 싶다 · 누군가에게 화내고 싶다 · 숨고 싶다 · 잘 모르겠다

> 감정은 저마다 무언가를 하라고 재촉해요. 지금 이 감정은 나에게 무엇을 하라고 하나요?

*작성 예시*: 피하고 싶다 — "발표를 다른 사람에게 넘기고 싶다."

**6. 이름 붙이기 문장**

> 이제 이렇게 말해 보세요.
> **"나는 지금 {감정1}과 {감정2}를 느끼고 있다. {부위}에서 느껴진다. 이 감정은 나에게 {행동}하라고 말하고 있다."** (쉼 5초)
> 
> 감정이 시키는 대로 꼭 해야 하는 건 아니에요. 알아차렸다면, 이제 선택할 수 있어요.

*작성 예시*: "나는 지금 불안과 부끄러움을 느끼고 있다. 가슴에서 느껴진다. 이 감정은 나에게 발표를 피하라고 말하고 있다."

## D. 마무리

[화면] 지금 감정의 강도는 몇 점인가요? 0~10 (시작 점수 {before} 함께 표시)

> 이름을 붙였다고 감정이 사라지지는 않아요. 그래도 이제 감정이 무엇인지, 무엇을 하라고 하는지 알게 됐어요.

**성찰 질문 1개**: "이 감정이 한 문장으로 말한다면, 무슨 말을 하고 있나요?" (예: "너는 망칠 거야")

**다음 연결** (5번 '시키는 행동' 답에 따라 자동 추천)
- 피하고 싶다 / 숨고 싶다 → AC03 기꺼이 경험하기 → DB03 반대 행동
- 계속 생각하고 싶다 / 확인하고 싶다 → 성찰 질문의 문장이 확인 가능한 예측이면 CB02 간이 사고기록지, 답이 없는 반복이면 AC01 탈융합 또는 CB03 걱정 미루기
- 화내고 싶다 → DB02 STOP
- 강도 7 이상 그대로 → BR01 또는 GR01

## E. 문제가 생길 때

| 어려움 | 대처 |
|---|---|
| 무슨 감정인지 모르겠어요 | 흔한 일이에요. '몸 상태' 묶음이나 '잘 모르겠음'을 골라도 돼요. 몸 어디서 느껴지는지부터 시작해도 좋아요. |
| 이름 붙이니까 오히려 감정이 더 커져요 | 감정을 처음 똑바로 보면 잠깐 커지는 것처럼 느껴질 수 있어요. 7점 이상으로 올라가면 멈추고 BR01이나 GR01로 몸부터 진정시키세요. |
| 매번 '불안'만 고르게 돼요 | 괜찮아요. 익숙해지면 '초조', '막막함'처럼 더 구체적인 단어를 하나씩 시도해 보세요. 구체적일수록 다음에 무엇을 할지 고르기 쉬워져요. |
| 감정을 느끼는 것 자체가 싫어요 | 감정을 느끼라는 게 아니라 '저기 있다'고 확인만 하는 거예요. 최소 버전으로 한 단어만 골라도 충분해요. |

**즉시 멈춰야 하는 신호**: 감정이 9~10점으로 치솟거나 숨이 가빠짐 → 멈추고 BR01 최소 버전 또는 GR01 최소 버전.

**위기 신호**: 4번에서 자해나 죽음에 대한 생각을 적었거나, 그런 생각이 든다면 위기 안내 화면(109 · 1577-0199 · 119)으로 이동합니다. (MVP는 글 자동 분석을 하지 않으므로, 이 화면에 "위기" 버튼을 항상 함께 표시)
