# JR01 저녁 3줄 기록

## A. 메타 정보

| 항목 | 내용 |
|---|---|
| 모듈 ID | JR01 |
| 이름 | 저녁 3줄 기록 |
| 출처 기법 | CBT의 구조화된 자기 관찰(불안 일지), ACT의 가치 행동 기록, 긍정 사건 기록(좋았던 일 세 가지 기법을 줄인 형태) |
| 겨냥 메커니즘 | ③ 회피(다가감·피함을 알아차림), ⑥ 감정 정리, ⑦ 주의 균형(좋았던 일) |
| 적합한 상태 | 매일 저녁 루틴(CB03 걱정 시간 바로 다음) |
| 피해야 할 상태 | 불안 7점 이상(→ 먼저 BR01·GR01, 기록은 한 줄만), 잠들기 직전 30분 이내(곱씹기 방지) |
| 소요 시간 | 최소 30초(점수 + 한 줄) / 기본 2분 / 확장 3~5분 |

**근거에 대한 메모**: 자기 관찰 기록은 CBT의 기본 도구로, 자신의 패턴을 알아차리고 치료 진행을 확인하는 데 쓰입니다. 좋았던 일을 기록하는 개입은 행복감을 조금 높인다는 연구가 있으나 효과가 작습니다(Davis et al., 2016). (근거 수준: 자기 관찰 도구로서 널리 쓰임 / 좋았던 일 기록 중간, 효과 작음)

**설계 의도**:
- 이 기록은 5단계 점검의 핵심 데이터입니다. 그래서 **짧고, 매일 같은 형식**으로 만듭니다.
- 오늘 앱에서 한 일(모듈 수행, DB03의 다가간 일, CB03 걱정 메모)은 **자동으로 채워 두고**, 사용자는 확인·추가만 합니다(2단계 수정 제안 10번 반영).
- 하루를 "불안했던 날"로만 끝내지 않도록, 마지막 줄은 항상 다가간 일 또는 좋았던 일입니다.
- 쉰 날을 묻지 않고, 연속 기록을 보여주지 않습니다(1단계 3장 다시 시작하기 규칙).

> 이 기록이 쌓이면, 어떤 상황에서 불안해지는지, 무엇이 도움이 됐는지 내 눈으로 볼 수 있게 돼요.

## C. 본 스크립트

### 최소 버전 (30초)

[화면]
> 오늘 하루, 점수로 남겨 볼까요?

- 오늘 전반적인 불안: 0~10
- 오늘 전반적인 기분: 0~10
- 오늘 에너지: 0~10

> 오늘을 한 줄로 남긴다면? (건너뛰기 가능)

*작성 예시*: "회의 전에 많이 긴장했지만 결국 의견을 말했다."

> 기록했어요. 오늘 하루도 지나왔네요.

### 기본 버전 (2분, 3줄)

[화면] 상단에 오늘 점수 3개(최소 버전과 같음), 아래에 3줄

**오늘 앱에서 한 것** (자동 표시, 수정 가능)

[화면] 예: "BR01 생리적 한숨 2회 · DB02 STOP 1회 · DB03 다가간 일: 회의에서 '저도 동의해요' 말하기 · 걱정 메모 3개"

**① 오늘 불안했던 순간**

> 오늘 가장 불안했던 순간은 언제였나요? 무슨 일이 있었나요?

[화면] 불안 메모·체크인 기록이 있으면 시각과 함께 보여주고 골라서 쓸 수 있게 함

*작성 예시*: "오후 2시, 팀장님 메시지를 받고 평가 걱정이 시작됐다. (불안 6)"

**② 그때 나는 무엇을 했나요?**

[화면] 선택 (복수 가능)
- 다가갔다 (피하지 않고 했다)
- 피했다 / 미뤘다
- 확인하거나 안심을 구했다 (검색, 다시 보기, 물어보기)
- 앱의 기술을 썼다 → 어떤 것: (오늘 한 모듈 목록에서 선택)
- 그냥 견뎠다
- 잘 모르겠다

> 한 줄 덧붙여도 좋아요. (선택)

*작성 예시*: 앱의 기술(DB02 STOP) + 확인했다 — "STOP을 하고 나서도 평가 기준을 두 번 더 찾아봤다."

> 피했거나 확인했어도 괜찮아요. 알아차린 것만으로 다음에 다르게 할 수 있는 힘이 생겨요.

**③ 오늘 다가간 일, 또는 좋았던 일 하나**

[화면] 오늘 DB03 완료 기록이 있으면 자동으로 보여주고 "이것 말고 더 있나요?"

> 아주 작은 것이어도 괜찮아요. 불안했지만 해낸 일, 아니면 그냥 좋았던 순간 하나.

*작성 예시*: "점심에 동료랑 산책하면서 웃었다." / "미루던 메일에 답장했다."

> (선택) 그 일에서 내가 한 역할은 무엇이었나요?

*작성 예시*: "내가 먼저 산책 가자고 했다."

**마무리 문장**

[화면] 아래 문장 중 하나를 날마다 돌아가며 표시 (1단계 자기자비 원칙)
- "오늘 하루도 지나왔어요. 수고 많았어요."
- "불안한 순간이 있었어도, 그게 오늘의 전부는 아니에요."
- "오늘 피한 일이 있어도 괜찮아요. 내일 다시 작은 걸음부터 하면 돼요."

### 확장 버전 (3~5분, 원할 때)
기본 버전 뒤에 아래 중 하나를 고를 수 있습니다.
- **내일의 작은 일**: "내일 다가가 볼 작은 일 하나" → 다음 날 아침 루틴에 표시 (DB03 사다리 다음 단계가 있으면 자동 추천)

## D. 마무리

> 기록은 여기까지예요. 이제 하루를 내려놓아도 괜찮아요.

[화면] (잠자리 전이라면) "잠이 안 올 것 같다면 BR02 확장 버전(소리 신호 모드)을 해볼 수 있어요" 버튼

**성찰 질문**: 기본 버전의 ①~③이 성찰 질문 역할을 하므로 별도로 두지 않습니다.

**주간 화면으로 이어지는 데이터**
- 하루 점수 3개의 추이
- ②의 선택 비율: 다가감 / 피함 / 확인 / 기술 사용 → **"다가간 날"과 "피한 날"의 비율 변화**가 핵심 지표(1단계 5장)
- ①에서 반복되는 상황(시간대, 키워드)

**다음 연결**
- 기록하다 불안이 7점 이상으로 올라감 → BR02 또는 GR01
- ②에서 "확인하거나 안심을 구했다"가 3일 이상 반복 → 주간 리뷰에서 DB03(안전행동 내려놓기) 제안

## E. 문제가 생길 때

| 어려움 | 대처 |
|---|---|
| 쓸 말이 없어요 | 최소 버전(점수 + 한 줄)이면 충분해요. 한 줄도 어렵다면 점수만 남겨도 돼요. |
| 불안했던 순간을 쓰다 보니 다시 불안해져요 | 상황을 자세히 다시 떠올리지 말고, 짧은 제목처럼만 쓰세요("오후 메시지"). 그래도 불안이 오르면 BR02로 숨을 고르고 ③으로 바로 넘어가세요. |
| 좋았던 일이 하나도 없었어요 | 그런 날도 있어요. "오늘 하루를 버텨 냈다", "이 기록을 쓰고 있다"도 오늘 해낸 일이에요. |
| 매일 피했다고 쓰게 돼서 자책하게 돼요 | 피한 것을 알아차린 건 변화의 시작이에요. 피한 날이 많다면 다가가기 사다리의 첫 단계를 더 작게 만들어 볼 때라는 신호예요. 자책 대신 "내일은 무엇을 더 작게 해볼까"로 바꿔 보세요. |
| 며칠 빼먹었어요 | 괜찮아요. 지난 날을 채우지 않아도 돼요. 오늘부터 다시 쓰면 돼요. |

**즉시 멈춰야 하는 신호**: 기록이 곱씹기로 바뀌어 10분 넘게 같은 일을 쓰고 있다면, 멈추고 ③(좋았던 일)으로 넘어가 마무리합니다.

**위기 신호**: 기분 점수 0~2점을 입력하면 "위기" 버튼을 강조해 표시하고, 기분 2점 이하가 3일 연속이면 1단계 6.2에 따라 상담 연락처를 안내합니다. 자해나 죽음에 대한 생각이 든다면 위기 안내 화면(109 · 1577-0199 · 119)으로 이동합니다.
