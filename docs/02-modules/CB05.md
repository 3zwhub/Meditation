# CB05 작은 행동 하나

## A. 메타 정보

| 항목 | 내용 |
|---|---|
| 모듈 ID | CB05 |
| 이름 | 작은 행동 하나 (5분 활동) |
| 출처 기법 | 행동활성화(Behavioral Activation; Martell, Dimidjian 등), CBT의 즐거움·성취감 활동 계획 |
| 겨냥 메커니즘 | ⑦ 활동 위축 → 우울 |
| 적합한 상태 | E. 무기력(기운이 없고 아무것도 하기 싫음), 기분·에너지 점수가 낮은 날, 불안으로 하루 종일 아무것도 못 한 날 |
| 피해야 할 상태 | 감정이 폭주하는 중(→ DB01·DB02), 극심한 피로로 휴식이 실제로 필요한 경우(→ 쉬는 것도 계획된 행동으로 선택 가능) |
| 소요 시간 | 최소 1분(고르고 시작) / 기본 5분(활동 포함) + 기록 30초 |

**근거에 대한 메모**: 행동활성화는 우울에 대한 효과가 여러 메타분석에서 확인되었고(Ekers et al., 2014), 중등도 이상 우울에서 인지치료·항우울제와 비슷한 효과를 보였다는 연구도 있습니다(Dimidjian et al., 2006). 이 모듈은 그중 "작은 활동 하나를 지금 하기"만 떼어 낸 것입니다. (근거 수준: 행동활성화 전체 강함 / 이 짧은 형태 예비. 앱 인용 전 원문 확인)

**설계 의도**: 이 프로젝트는 불안이 중심이지만, 불안으로 피하는 일이 늘면 기분이 가라앉기 쉽습니다(1단계 1.2의 ⑦). 이 모듈은 우울 신호에 대응하는 경로입니다. 핵심 원리는 **"기분이 나아지면 하자"가 아니라 "하다 보면 기분이 따라올 수 있다"**입니다.

## B. 시작 전 안내

> 이 연습은 순서를 바꿔 봐요. 기분이 따라오길 기다리지 않고, **5분짜리 작은 행동**부터 먼저 해보는 거예요.

[화면] 지금 기분은? 0~10 / 에너지는? 0~10

## C. 본 스크립트

### 최소 버전 (1분: 고르고 시작하기)

> 아래에서 지금 할 수 있을 것 같은 것 하나만 골라 보세요. 가장 쉬운 걸로요.

[화면] 추천 3개(에너지 점수에 맞춰, 아래 목록에서) + "전체 보기"

> 골랐다면, 지금 바로 시작해 보세요. 끝까지 하지 않아도 괜찮아요. 시작한 것만으로 충분해요.

[화면] "시작했어요" → 5분 타이머(선택) / "다른 걸로 바꿀래요"

### 기본 버전 (5분 + 기록)

**1. 고르기**

> 즐거움을 주는 것, 또는 '해냈다'는 느낌을 주는 것 중에서 5분 안에 할 수 있는 것을 골라 보세요.

[화면] 활동 목록 (에너지 점수 0~3이면 "아주 작은" 칸을 먼저 보여줌)

| 크기 | 즐거움 | 해냈다는 느낌(성취감) | 몸 |
|---|---|---|---|
| 아주 작은 (1~2분) | 좋아하는 노래 한 곡 듣기, 창밖 보기, 따뜻한 음료 마시기 | 컵 하나 씻기, 침대 정리, 답장 하나 보내기 | 기지개 켜기, 물 한 잔 마시기, 창문 열기 |
| 작은 (5분) | 좋아하는 사진 보기, 반려동물·식물 돌보기, 짧은 영상 하나(타이머 설정) | 책상 한 칸 정리, 빨래 개기, 내일 할 일 하나 적기 | 집 앞 5분 걷기, 샤워하기, 스트레칭 |
| 조금 큰 (10분 이상, 여유 있을 때) | 친구에게 연락하기, 좋아하는 음식 만들기 | 미루던 일 10분만 하기 | 산책, 가벼운 운동 |

[화면] "직접 추가" — 내가 추가한 활동은 다음부터 목록 맨 위에 표시

*작성 예시*: "집 앞 편의점까지 걸어가서 음료 하나 사 오기"

**2. 예상해 보기**

> 이걸 하면 얼마나 즐거울 것 같나요? 얼마나 '해냈다'는 느낌이 들 것 같나요?

[화면] 예상 즐거움 0~10 / 예상 성취감 0~10

*작성 예시*: 예상 즐거움 2 / 예상 성취감 3

**3. 하기**

> 지금 해보세요. 기분이 따라오지 않아도 괜찮아요. 몸을 움직이는 것 자체가 이 연습이에요.

[화면] 5분 타이머(선택) / "다 했어요" / "시작만 했어요"

**4. 실제로는?**

> 해보니 어땠나요?

[화면] 실제 즐거움 0~10 / 실제 성취감 0~10 / 지금 기분 0~10

*작성 예시*: 실제 즐거움 4 / 실제 성취감 5 / 기분 3 → 5

> 예상보다 나았나요? 우울할 때 마음은 활동이 얼마나 좋을지를 낮게 예상하곤 해요. 이 기록이 쌓이면, 마음의 예상과 실제가 얼마나 다른지 볼 수 있어요.

## E. 문제가 생길 때

| 어려움 | 대처 |
|---|---|
| 아무것도 할 기운이 없어요 | "아주 작은" 칸에서 가장 작은 것, 예를 들어 "물 한 잔 마시기"를 골라 보세요. 그것도 어렵다면 "창밖 1분 보기"도 행동이에요. |
| 했는데 기분이 전혀 안 나아졌어요 | 우울할 때는 활동의 효과가 바로 느껴지지 않는 경우가 많아요. 하루 한 번의 결과보다 일주일의 흐름을 보세요. 주간 화면에서 활동한 날과 안 한 날의 기분을 비교할 수 있어요. |
| 해야 할 일만 떠올라서 부담돼요 | '즐거움' 칸에서 골라 보세요. 해야 할 일이 아니어도 괜찮아요. |
| 쉬어야 할 것 같은데 억지로 하는 느낌이에요 | 정말 쉬는 게 필요하다면, "10분 동안 아무것도 안 하고 누워 있기"를 계획된 활동으로 골라도 돼요. 미루는 것과 쉬기로 선택하는 것은 달라요. |
