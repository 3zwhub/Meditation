# BR02 느린 호흡

## A. 메타 정보

| 항목 | 내용 |
|---|---|
| 모듈 ID | BR02 |
| 이름 | 느린 호흡 (4초 들이쉬고 6초 내쉬기) |
| 출처 기법 | 느린 호흡·공명 호흡 연구 (Zaccaro et al., 2018 체계적 고찰) |
| 겨냥 메커니즘 | ① 과잉 경보·신체 긴장 |
| 적합한 상태 | C. 회피 직전, B. 걱정 루프(첫 개입 전 정돈), 아침 기본 루틴, 잠들기 전 |
| 피해야 할 상태 | 불안 8점 이상으로 숨을 오래 참거나 세는 것 자체가 버거울 때 → BR01 또는 GR01 먼저 |
| 소요 시간 | 최소 1분(6회) / 기본 3분 / 확장 5분 |

**근거에 대한 메모**: 분당 6회 안팎의 느린 호흡은 심박변이도를 높이고 주관적 불안을 낮추는 경향이 여러 연구에서 보고되었습니다(Zaccaro et al., 2018). 연구마다 방법과 대상이 달라 효과 크기는 단정하기 어렵습니다. (근거 수준: 중간)

## B. 시작 전 안내

> 불안할 때 숨은 저절로 짧고 빨라져요. 숨을 천천히, 특히 내쉬는 숨을 길게 쉬면 몸이 긴장을 낮추는 쪽으로 움직이는 데 도움이 될 수 있어요.
> 화면의 원이 커질 때 들이쉬고, 작아질 때 내쉬기만 하면 돼요.

[화면] 지금 불안·긴장은 몇 점인가요? 0~10
[화면] 속도 선택: 기본(4초-6초) / 더 짧게(3초-5초)

## C. 본 스크립트

### 최소 버전 (1분, 6회)

[화면] 원 애니메이션: 4초 커짐(들이쉼) → 6초 작아짐(내쉼). 첫 2회만 음성 안내, 이후 소리 없이 진행

> 원이 커지면 코로 들이쉬세요. 하나, 둘, 셋, 넷. 
> 원이 작아지면 천천히 내쉬세요. 하나, 둘, 셋, 넷, 다섯, 여섯.
> 
> 한 번 더. 들이쉬고… 내쉬고…
> 
> 이제 원을 따라 혼자 이어가 보세요.
> (4회 반복)
> 
> 잘하셨어요.

### 기본 버전 (3분)

> 편하게 앉거나 누워 보세요. 한 손을 배 위에 얹어도 좋아요. (쉼 3초)
> 
> 먼저 지금 숨을 그대로 느껴 보세요. 바꾸려 하지 않아도 돼요. (쉼 5초)
> 
> 이제 원을 따라 숨의 속도를 조금 늦춰 볼게요.
> 숨을 크게 쉴 필요는 없어요. 평소 양 그대로, 속도만 천천히요. (쉼 2초)
> 
> 원이 커지면 코로 들이쉬세요. 배 위의 손이 살짝 올라오는 걸 느껴 보세요. (4초)
> 원이 작아지면 입이나 코로 천천히 내쉬세요. (6초)
>
> [화면] 원 애니메이션 반복. 약 40초마다 아래 문장 중 하나를 순서대로 넣음
>
> - "내쉬는 숨이 끝날 때, 몸이 의자나 바닥에 조금 더 기대는 걸 느껴 보세요."
> - "생각이 다른 곳으로 가는 건 자연스러운 일이에요. 알아차리면 원으로 돌아오면 돼요."
> - "숨이 부족하게 느껴지면 '더 짧게' 속도로 바꾸거나, 편한 대로 쉬어도 괜찮아요."
> - "지금 이 순간에는 숨 쉬는 것 말고 할 일이 없어요."
>
> (2분 50초 지점)
> 마지막 숨이에요. 들이쉬고… 길게 내쉬세요.
> 이제 원을 놓아주고 평소처럼 숨 쉬세요. (쉼 5초)

### 확장 버전 (5분)
기본 버전과 같지만, 1분 이후에는 원 애니메이션 없이 부드러운 소리 신호(들이쉼 시작, 내쉼 시작)만 들리게 해 눈을 감고 할 수 있게 합니다. 잠들기 전에 쓰기 좋습니다.

## D. 마무리

[화면] 지금 불안·긴장은 몇 점인가요? 0~10 (시작 점수 {before} 함께 표시)

> 숨을 고른 지금이 다음 일을 하기 좋은 때예요. 불안이 조금 남아 있어도, 그 상태로 시작할 수 있어요.

**성찰 질문 1개**: "지금 바로 하고 싶은 일, 또는 해야 할 일 하나는 무엇인가요?" (짧은 입력, 건너뛰기 가능)

**다음 연결**
- 피하려던 일이 있었음 → AC03 기꺼이 경험하기 → DB03 반대 행동
- 걱정이 계속 돎 → CB01 감정 이름 붙이기 → AC01 탈융합 또는 CB03 걱정 미루기
- 아침 루틴 중 → 오늘의 확언(AF01) → "오늘 다가갈 작은 일 하나" 정하기

## E. 문제가 생길 때

| 어려움 | 대처 |
|---|---|
| 6초 내쉬기가 너무 길어요 | '더 짧게(3초-5초)'로 바꾸세요. 중요한 건 숫자가 아니라 내쉬는 숨이 들이쉬는 숨보다 조금 긴 것이에요. |
| 숨이 부족하고 답답해요 | 숨을 너무 깊게 쉬려 하고 있을 수 있어요. 양은 평소처럼, 속도만 늦추세요. 답답함이 커지면 멈추고 평소 숨으로 돌아오세요. |
| 숫자를 세다 보면 더 긴장돼요 | 숫자를 세지 말고 원만 보세요. 원도 부담스러우면 소리 신호 모드를 쓰세요. |
| 졸려요 | 잠들기 전이라면 괜찮아요. 낮이라면 눈을 뜨고 앉은 자세로 해보세요. |

**즉시 멈춰야 하는 신호**: 숨이 막히는 느낌이 공황으로 커짐, 어지러움이나 손발 저림이 계속됨 → 멈추고 GR01(눈 뜨고 바깥 감각에 집중)으로 바꾸기.

**위기 신호**: 자해나 죽음에 대한 생각이 든다면 연습을 멈추고 위기 안내 화면(109 · 1577-0199 · 119)으로 이동합니다.
