# MD02 생각 관찰

## A. 메타 정보

| 항목 | 내용 |
|---|---|
| 모듈 ID | MD02 |
| 이름 | 생각 관찰 (생각에 이름 붙이고 돌아오기) |
| 출처 기법 | 마음챙김 기반 인지치료(MBCT)의 생각 관찰, 열린 주의 명상, 생각 라벨링(noting) |
| 겨냥 메커니즘 | ② 걱정·반추 |
| 적합한 상태 | F. 안정(가장 좋은 연습 시간), B. 걱정 루프가 가라앉은 뒤 재발 예방, 아침·저녁 확장 루틴 |
| 피해야 할 상태 | 불안 7점 이상(→ BR01·GR01), 걱정 루프 한가운데(→ 먼저 DB02·AC01) |
| 소요 시간 | 최소 1분 / 기본 3분 / 확장 5분 |

**근거에 대한 메모**: 마음챙김 기반 프로그램은 불안을 줄이는 근거가 있고(Hofmann et al., 2010), MBSR은 불안장애에서 항우울제(에스시탈로프람)와 비슷한 효과를 보였다는 무작위 연구도 있습니다(Hoge et al., 2023). 이 모듈의 짧은 생각 관찰만 따로 검증한 것은 아닙니다. (근거 수준: 프로그램 전체 중간~강함 / 짧은 단독 연습 예비)

**AC01과의 차이**: AC01은 **지금 나를 붙잡은 생각 하나**를 다루는 응급 기술입니다. MD02는 특정 생각 없이, **어떤 생각이 오든 알아차리고 돌아오는 힘**을 평소에 기르는 연습입니다. 안정된 날에 MD02를 연습해 두면 불안한 날에 AC01이 더 잘 됩니다.

**닻(돌아올 곳) 선택**: 기본은 호흡이지만, 호흡에 집중하면 불안해지는 사람을 위해 **소리**를 닻으로 고를 수 있습니다(1단계 6.4).

## B. 시작 전 안내

> 마음은 가만히 두면 저절로 과거와 미래를 오가요. 그건 뇌가 원래 하는 일이에요. 문제는 생각이 오는 게 아니라, 생각에 끌려가 정신을 차려 보니 한참 걱정하고 있는 거죠.
> 이 연습에서는 생각이 올 때마다 **"아, 생각이 왔구나"** 하고 알아차리고, 정해 둔 곳으로 돌아와요. 생각을 멈추려는 게 아니라, 알아차리는 순간을 연습하는 거예요.

[화면] 돌아올 곳 선택: 호흡 / 주변 소리
[화면] 지금 생각이 얼마나 시끄러운가요? 0~10

## C. 본 스크립트

### 최소 버전 (1분)

> 편하게 앉아, 숨을 한 번 내쉬어 보세요. (쉼 3초)
> {호흡: 숨이 코끝이나 배에서 오가는 걸 느껴 보세요 / 소리: 지금 들리는 소리에 귀를 열어 보세요}. (쉼 5초)
> 
> 생각이 떠오르면, 마음속으로 짧게 이름을 붙여 보세요. "걱정", "계획", "기억", 또는 그냥 "생각".
> 그리고 다시 {호흡 / 소리}으로 돌아오세요. (쉼 40초)
> 
> 몇 번 돌아왔나요? 돌아온 횟수만큼 연습한 거예요.

### 기본 버전 (3분)

> 편한 자세로 앉아 보세요. 눈은 감거나, 앞쪽 바닥을 부드럽게 바라보세요. (쉼 3초)
> 
> **1. 닻 내리기 (30초)**
> {호흡: 숨이 들어오고 나가는 곳을 하나 골라 보세요. 코끝, 가슴, 배. 그곳에서 숨을 느껴 보세요. 숨을 조절하지 않아도 돼요. /
> 소리: 지금 들리는 소리에 귀를 열어 보세요. 가까운 소리, 먼 소리. 소리를 판단하지 않고, 그냥 들려오는 대로요.} (쉼 20초)
> 
> **2. 생각 알아차리기 (2분)**
> 이제 생각이 떠오르면, 그 생각에 짧게 이름을 붙여 볼 거예요.
> 
> [화면] 이름표 예시(작게 표시): 걱정 · 계획 · 기억 · 판단 · 상상 · 할 일 · 그냥 "생각"
> 
> 이름표는 정확하지 않아도 돼요. 붙이고 나면 생각을 따라가지 말고, 다시 {호흡 / 소리}으로 돌아오세요. (쉼 20초)
> 
> 생각을 하늘을 지나가는 구름처럼 바라봐도 좋아요. 구름은 오고, 머물고, 지나가요. 하늘은 그대로예요. (쉼 25초)
> 
> 같은 생각이 계속 돌아올 수도 있어요. 그럴 땐 "또 왔구나", 그리고 돌아오세요. (쉼 25초)
> 
> 한참 생각을 따라갔다는 걸 알아차렸다면, 그 알아차린 순간이 바로 이 연습의 핵심이에요. 스스로를 탓하지 말고, 부드럽게 돌아오세요. (쉼 30초)
> 
> **3. 마무리 (30초)**
> 이제 이름 붙이기를 내려놓고, {호흡 / 소리}을 한 번 더 느껴 보세요. (쉼 10초)
> 주변의 공간을 느끼며, 준비되면 눈을 떠 주세요.

[화면] (선택) 연습 중 "생각을 알아차릴 때마다 화면 톡" 모드: 누른 횟수를 기록. 기록이 쌓이면 "알아차림 횟수"를 보여주되, 많을수록 좋다/나쁘다는 평가는 하지 않음

### 확장 버전 (5분)
기본 버전 2번을 4분으로 늘리고, 후반 1분은 이름표 없이 "생각이 오고 가는 것을 그냥 바라보기(열린 주의)"로 바꿉니다.

## D. 마무리

[화면] 지금 생각이 얼마나 시끄러운가요? 0~10 / 생각과 나 사이에 거리가 느껴졌나요? 0~10

> 생각이 계속 왔다면, 그만큼 많이 연습한 거예요. 생각이 조용해지는 게 목표가 아니에요.

**성찰 질문 1개**: "가장 자주 붙인 이름표는 무엇이었나요?" (걱정 / 계획 / 기억 / 판단 / 상상 / 할 일 / 기타) — 쌓이면 주간 화면에 "자주 찾아오는 생각의 종류" 표시. "걱정"이 많으면 CB03 걱정 미루기를 함께 제안

**다음 연결**
- 아침 → 오늘의 확언(AF01) → "오늘 다가갈 작은 일"
- 특정 걱정이 반복해서 돌아옴 → AC01 탈융합 또는 CB03 걱정 메모
- 안정된 날 → 그대로 하던 일로

## E. 문제가 생길 때

| 어려움 | 대처 |
|---|---|
| 생각이 너무 많아서 이름 붙일 틈이 없어요 | 이름표를 하나로 줄이세요. 무엇이든 그냥 "생각". 그래도 많으면 닻을 소리로 바꾸거나 최소 버전만 해보세요. |
| 생각에 빠졌다가 한참 뒤에야 알아차려요 | 그게 정상이고, 바로 그 알아차림이 연습이에요. 처음엔 몇 분씩 빠져 있다가, 연습할수록 조금씩 빨리 알아차리게 돼요. |
| 이름을 붙이니 오히려 그 걱정이 커져요 | 이름표를 붙인 뒤 내용을 따라가고 있을 수 있어요. 이름만 붙이고 바로 닻으로 돌아오세요. 7점을 넘으면 멈추고 GR01. |
| 호흡에 집중하니 숨이 답답해요 | 닻을 "주변 소리"로 바꾸세요. 숨을 관찰하면 숨을 조절하게 되어 답답해지는 경우가 많아요. |
| 지루해요 | 지루함도 하나의 이름표예요. "지루함"이라고 붙이고 돌아오세요. 짧은 버전부터 시작해도 충분해요. |

**즉시 멈춰야 하는 신호**: 고통스러운 기억이 반복해서 밀려오거나 현실감이 떨어짐 → 눈을 뜨고 멈춘 뒤 GR01. 반복되면 전문가와 상의를 권합니다.

**위기 신호**: 떠오르는 생각이 자해나 죽음에 대한 것이라면 관찰을 계속하지 말고 위기 안내 화면(109 · 1577-0199 · 119)으로 이동합니다.
