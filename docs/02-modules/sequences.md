# 연결 콘텐츠: 하루 일정 예시와 조합 시퀀스

1·2회차 모듈(BR01, BR02, GR01, CB01, DB02, AC01, CB03, CB02, AC03, DB03)로 구성했습니다. 괄호 안의 모듈은 3회차에서 작성합니다.

## 하루 일정 예시 (정해진 루틴 약 7~9분 + 필요할 때 1분 안팎의 짧은 개입)

평일, 일상적인 걱정과 긴장이 있는 날 기준입니다.

| 시각 | 상황 | 모듈 | 시간 |
|---|---|---|---|
| 07:30 | 일어나서 | 체크인(불안 5) → **BR02 느린 호흡 최소(1분)** → (AF01 오늘의 확언) → "오늘 다가갈 작은 일 하나" 정하기 | 2분 |
| 11:00 | 회의 직전, 가슴이 두근거림 | **BR01 생리적 한숨 최소(3회)** | 30초 |
| 14:20 | 상사의 메시지를 받고 걱정이 맴돎(불안 6) | **DB02 STOP 최소** → **CB01 감정 이름 붙이기 최소** → **CB03 걱정 메모**("걱정 시간에 다루자") | 1분 30초 |
| 16:00 | 미루던 메일 답장 앞에서 얼어붙음 | **AC03 기꺼이 경험하기 최소** → **DB03 반대 행동 최소**(첫 문장만 쓰기) | 1분 + 실행 |
| 18:40 | 퇴근길 지하철에서 갑자기 숨이 가쁨(불안 8) | **GR01 그라운딩 최소** (눈 뜨고, 소리 없이 화면만 보며) | 1분 |
| 21:30 | 걱정 시간 | **CB03 걱정 시간**(메모 다시 보고 분류) | 3~5분 |
| 21:35 | 이어서 | (JR01 저녁 3줄 기록) | 2분 |
| 22:15 | 잠자리 | (선택) **BR02 확장 버전**, 소리 신호 모드 | 5분 |

> 정해진 루틴은 아침(2분)과 저녁 걱정 시간·기록(5~7분)입니다. 낮의 개입은 불안이 올 때만 쓰며, 많은 날은 한두 번이면 충분합니다. 이 예시처럼 불안한 순간이 여러 번인 날은 하루 10분을 조금 넘을 수 있습니다.
> 잠자리의 BR02 확장 버전은 잠이 안 올 때만 쓰는 선택 사항입니다.
> 컨디션이 나쁜 날은 아침 체크인 + BR01 3회 + 저녁 한 줄 기록(총 1분)만 해도 "오늘 했다"로 기록됩니다.

## 조합 시퀀스

### 시퀀스 1: 몸이 먼저 반응할 때 (급성 불안 → 정돈)
**언제**: 갑자기 심장이 뛰고 숨이 가빠짐, 불안 7점 이상
**총 시간**: 3~4분

```
GR01 최소 (1분)          바깥 감각으로 주의를 옮겨 경보를 낮춤
   │  불안이 조금 내려감 (예: 8 → 6)
   ▼
BR01 기본 일부 (1분)      긴 날숨으로 몸의 긴장을 더 낮춤
   │  (6 → 5)
   ▼
CB01 최소 (1분)           "나는 지금 두려움을 느끼고 있다"
   │
   ▼
"하던 일로 돌아가 볼까요?"
```

**왜 이 순서인가**: 각성이 높을 때는 몸 안의 감각(호흡)보다 바깥 감각(GR01)이 덜 부담스럽습니다. 각성이 조금 내려가면 호흡으로 몸을 더 정돈하고, 생각할 여유가 생겼을 때 감정에 이름을 붙입니다(1단계 1.4 "몸 → 마음 → 행동").
**목표는 불안 0점이 아닙니다.** 하던 일로 돌아갈 수 있으면 충분합니다.

### 시퀀스 2: 걱정이 멈추지 않을 때 (걱정 루프 → 선택)
**언제**: 같은 걱정이 머릿속에서 맴돌고, 검색하거나 누군가에게 확인하고 싶어짐, 불안 4~6점
**총 시간**: 4~5분

```
DB02 STOP 기본 (2분)      확인·검색 충동을 멈추고, 사실과 해석을 나눔
   │
   ▼
CB01 기본 5~6번 (1분)     감정과 "이 감정이 시키는 행동" 확인
   │
   ├─ 해석이 확인 가능한 예측 ───► CB02 간이 사고기록지 최소 (3분)
   │                                    │ 8번 "확인해 볼 수 있다면"
   │                                    ▼
   │                               DB03 반대 행동 (직접 확인)
   │
   └─ 답이 없는 "만약 ~하면?" ───► AC01 탈융합 최소 (1분)
                                    │ 그래도 하루 종일 반복되면
                                    ▼
                               CB03 걱정 메모 → 저녁 걱정 시간
```

**왜 이 순서인가**: 걱정이 맴돌 때 가장 먼저 해야 할 것은 걱정의 답을 찾는 게 아니라, 확인·검색 같은 안전행동을 멈추는 것입니다(1단계 1.1 고리의 ③). 그다음 생각의 종류에 따라 CBT로 따져볼지, ACT로 거리를 둘지 고릅니다(1단계 1.4).

### 시퀀스 3: 피하고 싶은 일 앞에서 (회피 직전 → 다가가기)
**언제**: 해야 하거나 하고 싶은 일이 있는데 불안해서 미루게 됨, 불안 4~7점
**총 시간**: 계획 4~5분 + 실행

```
BR02 느린 호흡 최소 (1분)       몸을 조금 정돈
   │
   ▼
AC03 기꺼이 경험하기 기본 (2분)  불안이 있을 자리를 내주고, 이 일이 왜 중요한지 확인
   │  기꺼이 하는 정도 1점 이상
   ▼
DB03 반대 행동 기본 (3분)        사실 확인 → 사다리 → 예상 적기 → 안전행동 하나 내려놓기
   │
   ▼
실행 → 결과 기록 (1분)           예상 vs 실제 비교, "다가간 일" 자동 기록
```

**왜 이 순서인가**: 진정(BR02)만으로 끝내면 진정 기법이 회피의 일부가 될 수 있습니다(1단계 1.1). AC03으로 "불안이 있어도 움직일 이유"를 확인하고, DB03으로 실제 행동과 예상 검증까지 가야 고리의 ③·④가 끊어집니다. 성과는 불안 점수가 아니라 **예상과 실제의 차이**와 **다가간 일 수**로 봅니다.
