# 연결 콘텐츠: 하루 일정 예시와 조합 시퀀스

1회차 모듈(BR01, BR02, GR01, CB01, DB02)만으로 구성했습니다. 2·3회차 모듈이 나오면 괄호 안의 모듈이 채워집니다.

## 하루 일정 예시 (하루 총 약 8분)

평일, 일상적인 걱정과 긴장이 있는 날 기준입니다.

| 시각 | 상황 | 모듈 | 시간 |
|---|---|---|---|
| 07:30 | 일어나서 | 체크인(불안 5) → **BR02 느린 호흡 최소(1분)** → (AF01 오늘의 확언) → "오늘 다가갈 작은 일 하나" 정하기 | 2분 |
| 11:00 | 회의 직전, 가슴이 두근거림 | **BR01 생리적 한숨 최소(3회)** | 30초 |
| 14:20 | 상사의 메시지를 받고 걱정이 맴돎(불안 6) | **DB02 STOP 최소** → **CB01 감정 이름 붙이기 최소** → (AC01 탈융합 또는 CB03 걱정 미루기) | 2분 |
| 18:40 | 퇴근길 지하철에서 갑자기 숨이 가쁨(불안 8) | **GR01 그라운딩 최소** (눈 뜨고, 소리 없이 화면만 보며) | 1분 |
| 22:00 | 자기 전 | (JR01 저녁 3줄 기록) | 2~3분 |
| 22:15 | 잠자리 | (선택) **BR02 확장 버전**, 소리 신호 모드 | 5분 |

> 잠자리의 BR02 확장 버전은 하루 총량에 넣지 않습니다. 잠이 안 올 때만 쓰는 선택 사항입니다.
> 컨디션이 나쁜 날은 아침 체크인 + BR01 3회 + 저녁 한 줄 기록(총 1분)만 해도 "오늘 했다"로 기록됩니다.

## 조합 시퀀스

### 시퀀스 1: 몸이 먼저 반응할 때 (급성 불안 → 정돈)
**언제**: 갑자기 심장이 뛰고 숨이 가빠짐, 불안 7점 이상
**총 시간**: 3~4분

```
GR01 최소 (1분)          바깥 감각으로 주의를 옮겨 경보를 낮춤
   │  불안이 조금 내려감 (예: 8 → 6)
   ▼
BR01 기본 일부 (1분)      긴 날숨으로 몸의 긴장을 더 낮춤
   │  (6 → 5)
   ▼
CB01 최소 (1분)           "나는 지금 두려움을 느끼고 있다"
   │
   ▼
"하던 일로 돌아가 볼까요?"
```

**왜 이 순서인가**: 각성이 높을 때는 몸 안의 감각(호흡)보다 바깥 감각(GR01)이 덜 부담스럽습니다. 각성이 조금 내려가면 호흡으로 몸을 더 정돈하고, 생각할 여유가 생겼을 때 감정에 이름을 붙입니다(1단계 1.4 "몸 → 마음 → 행동").
**목표는 불안 0점이 아닙니다.** 하던 일로 돌아갈 수 있으면 충분합니다.

### 시퀀스 2: 걱정이 멈추지 않을 때 (걱정 루프 → 선택)
**언제**: 같은 걱정이 머릿속에서 맴돌고, 검색하거나 누군가에게 확인하고 싶어짐, 불안 4~6점
**총 시간**: 4~5분

```
DB02 STOP 기본 (2분)      확인·검색 충동을 멈추고, 사실과 해석을 나눔
   │
   ▼
CB01 기본 5~6번 (1분)     감정과 "이 감정이 시키는 행동" 확인
   │
   ├─ 해석이 확인 가능한 예측 ───► (CB02 간이 사고기록지)
   │
   └─ 답이 없는 "만약 ~하면?" ───► (AC01 탈융합) 또는 (CB03 걱정 미루기)
                                    1회차만 있을 때: BR02 최소 1분 후
                                    STOP의 P에서 "조금 기다렸다가 다시 생각한다" 선택
```

**왜 이 순서인가**: 걱정이 맴돌 때 가장 먼저 해야 할 것은 걱정의 답을 찾는 게 아니라, 확인·검색 같은 안전행동을 멈추는 것입니다(1단계 1.1 고리의 ③). 그다음 생각의 종류에 따라 CBT로 따져볼지, ACT로 거리를 둘지 고릅니다(1단계 1.4).
