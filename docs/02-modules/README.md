## 모든 모듈 공통 규칙

### 형식
모든 모듈은 A(메타 정보) · B(시작 전 안내) · C(본 스크립트: 최소/기본) · D(마무리) · E(문제가 생길 때) 순서를 지킵니다. 3단계에서 이 구조를 그대로 데이터로 옮깁니다.

### 0~10 점수 기준 (모든 전후 점수에 공통)
| 점수 | 의미 |
|---|---|
| 0 | 전혀 없음 |
| 3 | 약간 있지만 하던 일을 할 수 있음 |
| 5 | 꽤 신경 쓰이고 집중이 어려움 |
| 7 | 강해서 다른 것을 하기 어려움 |
| 10 | 상상할 수 있는 가장 강한 정도 |

### 스크립트 표기
- `(쉼 N초)`: 음성 안내나 화면 문구 사이에 둘 침묵
- `[화면]`: 문장이 아니라 화면에 보여줄 요소(애니메이션, 버튼, 입력칸)
- `{ }`: 사용자 입력이나 이전 단계 값으로 채워지는 자리

### 말투
- "~해 보세요", "~해도 괜찮아요"처럼 초대하는 말투. "~해야 합니다"는 쓰지 않습니다.
- "다 잘될 거예요", "불안을 없애 드릴게요" 같은 약속을 하지 않습니다.
- 점수가 내려가지 않아도 실패로 표현하지 않습니다.
